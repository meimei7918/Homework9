WebGIS

A geographic information system (GIS) is a computer-based information system that enables capture, modeling, storage, retrieval, sharing, manipulation, analysis, and presentation of geographically referenced data.

WebGIS is a information system, comprising at least a server and a client, where the server is a GIS server and the client is a web browser or mobile applications. In short, WebGIS can be defined as any GIS that uses web technology to communicate between a server and a client.

Advantages of WebGIS

  • global reach, large number of users, better cross-platform capability, low cost as averaged by the number of users, easy to use, unified updates, and diverse applications, etc.

OpenLayers

OpenLayers is an open source JavaScript library for displaying map data. It makes easier to build a dynamic map and has been developed to further the use of geographic information of all kinds.

It can display map tiles, vector data and markers loaded from any sources.

Current version: 10.11.0 (Notice: examples shown on webpages are JavaScript ES6 (ECMAScript 6) (compiled needed))

  • 283 examples
  • Start from version 5: compiled needed (node.js server)
  • Writing scripts based on version 4.6.5 is recommended. Please refer source code of examples from GitHub
    https://github.com/openlayers/openlayers/releases/tag/v4.6.5
    • V4.6.5-dist.zip (lib, css)
    • V4.6.5.zip (examples)

Support data formats

  • GeoJSON, KML, Geography Markup Language (GML)
  • Well-Known Text (WKT)(text markup language for representing vector geometry objects)
  • GeoRSS, GPX, etc.

How to write

To build a map in a web page needs three things

  1. Include OpenLayers (*.js) and its CSS ( from https://openlayers.org/download/)
    • <script src="https://cdn.jsdelivr.net/npm/ol@v10.11.0/dist/ol.js"></script>
    • <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/ol@v10.11.0/ol.css">
    • Or download the library as local files → no need for the Internet to connect
  2. A map container (HTML element)
    The map in the application is contained in a <div> HTML element.
    Must be a Div container: <div id='map'></div>
  3. JavaScript to create a simple map (JavaScript script)
    1. Creates an OpenLayers Map object via ol.Map.
    2. Attaches the map object to the <div> via target argument.
    3. Set layers for the map. Layers in OpenLayers are defined with a type (Image, Tile or Vector) which contains a source.
    4. Specify a view for the map, such as the center, resolution, and rotation of the map.

To build a map in a web page needs three things

  • Include OpenLayers library (*.js, *.css), <div id='map'>, create a simple map.
<!DOCTYPE html>
<html lang="zh-TW">
  <head>
    <script src="https://cdn.jsdelivr.net/npm/ol@v10.11.0/dist/ol.js"></script>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/ol@v10.11.0/ol.css">
    <style>
      html,body{
        margin: 0px;
        padding: 0px;
        height:100%;
      }
      #map {
        margin: 0px;
        padding: 0px;
        height: 100%;
        width: 100%;
      }
    </style>
    <title>OpenLayers map demo</title>
  </head>
  <body>
    <div id="map" class="map"></div>
    <script type="text/javascript">
      let projection = ol.proj.get('EPSG:3857'); //取得投影座標系統
      /*
      3857的格式是[minX, minY, maxX, maxY]
      這邊取得的是 Web Mercator 的全球投影範圍，不是台灣的範圍
      */
      let projectionExtent = projection.getExtent(); //取得投影範圍
      let size = ol.extent.getWidth(projectionExtent) / 256; //計算初始解析度
      /*
      ol.extent.getWidth(projectionExtent) 會計算投影範圍的寬度
      數字代表 Zoom 0 時，每個圖磚像素對應的投影平面距離
      因為每個圖磚是256*256(WMTS 圖磚網格採用常見的 256 × 256 像素)
      */
      let resolutions = new Array(20); //每個縮放層級對應的地圖解析度 20-> 23
      let matrixIds = new Array(20);   //每個縮放層級在 WMTS 中的矩陣識別碼
      for (let z = 0; z < 20; ++z) { //不同 Zoom 的解析度
        resolutions[z] = size / Math.pow(2, z);
        matrixIds[z] = z;
      }/**/

      let map = new ol.Map({            //create a OpenLayers Map object
        target: 'map',
        layers: [
          //加入 Google Maps 圖層
          new ol.layer.Tile({    //Google map
              visible: false,
              source: new ol.source.XYZ({
                crossOrigin: 'anonymous', //載入圖磚圖片時的跨來源請求模式，不會攜帶跨來源憑證
                url: 'https://mt{0-3}.google.com/vt/lyrs=m&x={x}&y={y}&z={z}',
              }),/**/
          }),
          //加入臺灣通用電子地圖（WMTS）
          new ol.layer.Tile({          //通用電子地圖
            extent: projectionExtent,  //限制圖層的繪製範圍
            source: new ol.source.WMTS({
              url: 'http://wmts.nlsc.gov.tw/wmts?', //提供地圖的伺服器網址
              layer: 'EMAP', //指定臺灣通用電子地圖這個layer
              matrixSet: 'GoogleMapsCompatible', //採用與 Google 地圖圖磚系統相容的矩陣規則
              format: 'image/jpeg',
              projection: projection, //使用前面設定的 EPSG:3857
              tileGrid: new ol.tilegrid.WMTS({ //tileGrid：圖磚如何排列
                origin: ol.extent.getTopLeft(projectionExtent), //origin：圖磚的起點,取得整個投影範圍左上角的座標
                resolutions:resolutions, //每個層級的解析度
                matrixIds:matrixIds,     //每個層級的編號
              }),
              extent: projectionExtent, //設定資料來源的範圍
              style: 'default'
            })
          })
        ],
        view: new ol.View({
          center: ol.proj.transform([121.751,23.8],'EPSG:4326','EPSG:3857'),
          zoom: 4  //8
        })
      });
    </script>
  </body>
</html>

Google maps layer types (lyrs)

  • h = roads only
  • m = standard roadmap
  • p = terrain
  • r = somehow altered
  • roadmap
  • s = satellite only
  • t = terrain only
  • y = hybrid
