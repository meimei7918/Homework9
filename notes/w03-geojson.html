課堂筆記

GeoJSON 的結構

一個 Feature ＝ 幾何 geometry ＋ 屬性 properties。幾何類型有 Point、LineString、Polygon，以及前面加 Multi 的版本。

{
  "type": "Feature",
  "properties": { "name": "臺北車站", "category": "交通" },
  "geometry": { "type": "Point", "coordinates": [121.517, 25.0478] }
}

Polygon 的座標多包一層陣列（外環＋可能的內環），而且第一點和最後一點要一樣才算封閉。

疑問與解答

為什麼 circleMarker 也吃 style？

因為 circleMarker 其實是向量圖形（Path），跟線、面一樣有 color、fillColor。一般的 L.marker 是圖片圖示，就不吃 style。

雙擊打開 HTML，fetch GeoJSON 為什麼出現 CORS 錯誤？

file:// 協定下瀏覽器不允許 fetch 本機檔案。在專案資料夾執行 python3 -m http.server，改用 http://localhost:8000 開就好。放到 GitHub Pages 上也沒問題。
