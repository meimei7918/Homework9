Style：Point

image: new ol.style.Circle({
    radius: 7, //大小
    fill: new ol.style.Fill({color: 'black'}), //填滿
    stroke: new ol.style.Stroke({              //外框
      color: [255,0,0], width: 2               //可以設定寬度
    })
})

image: new ol.style.Icon({
    crossOrigin: 'anonymous', //跨域資料
    src:'https://maps.google.com/mapfiles/ms/icons/red-dot.png', //引用樣式
    })
})

Style：Line

stroke: new ol.style.Stroke({
		color: 'rgba(100, 100, 100, 0.5)',
		width: 5,
		lineDash: [4,8]          //虛線
}),

Style：Polygon

stroke: new ol.style.Stroke({
		color: 'rgba(100, 100, 200, 0.7)',
		width: 6
}),
		fill: new ol.style.Fill({
		color: 'rgba(0, 0, 255, 0.3)'
})

Coordinate：Include proj4

proj4.defs(”EPSG code”, “projection definition”)

proj4.defs( 'urn:ogc:def:crs:OGC:1.3:CRS:84', proj4.defs('EPSG:4326') )

為另一個座標系統識別名稱提供定義。

urn:ogc:def:crs:OGC:1.3:CRS:84 是 OGC 使用的座標系統識別名稱

座標軸順序定義可能有所不同。這裡直接重用 EPSG:4326 的 Proj4 定義

ol.proj.proj4.register(proj4) → 註冊
