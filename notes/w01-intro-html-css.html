Introduction

The definition of GIS: A Geographic information system (GIS) is a computer-based information system that enables capture, modeling, storage, retrieval, sharing, manipulation, analysis, and presentation of geographically referenced data (Worboys and Duckham, 2004).

Five Components: Users(not only people now, agents as well), Hardware(data processing efficiency, like GPU), Method, Software, Data

HTML：What is HTML?

HyperText Markup Language (HTML) is a markup language for creating web pages.

  • HTML describes the structure of web pages. If you put it on a web server, it can open as a website; however, if you simply open it, it looks like a Word file.
  • HTML elements are represented by tags and contents
  • Browsers do not display the HTML tags, but use them to render the content of the page
  • File extension: *.html or *.htm
  • Current version: HTML 5 (living standard)

Basic structure of a HTML document

  • The <!DOCTYPE html> declaration defines this document to be HTML5: 開始的宣告
  • The <html> element is the root element
  • The <head> element contains meta information
  • The <title> element specifies a title for the document: Title的話是包含<title>宣告
  • The <body> element contains the visible page content: 內文的話是包含<body>宣告

Nested HTML Elements

  • <element attribute="value">
    • HTML elements/tags are not case sensitive
    • usually consists of a start tag and end tag
  • Comments: <!-- write anything -->
<!DOCTYPE html> <!--Declaration-->
<html><!--begin tag-->
	<head> <!--begin tag-->
		<title>This is Chiao-Ling's Webpage</title>
		<!-- This is a comment -->
	</head> <!--end tag-->
	<body> <!--same structural location(?) with head-->
	...
	</body>
</html><!--end tag-->
  • The DOM is a W3C (World Wide Web Consortium) standard.When a web page is loaded, the browser creates a DOM of the page. → When the server reads the file/code, it stores each element. 以DOM物件方式儲存
  • The HTML DOM model is constructed as a tree of Objects which enables to get, change, add, or delete HTML elements.

HTML Head

The <head> element is a container for metadata including:

  • The <title> element defines the title of the document and is required in all HTML/XHTML documents.
  • The <style> element is used to define style information for a single HTML page.
  • The <link> element is used to link to external style sheets.
  • The <meta> element is used to specify which character set is used, page description, keywords, author, and other metadata.
  • The <script> element is used to define client-side JavaScript.

CSS Introduction

Cascading Style Sheets (CSS) is a style sheet language that describes the style of an HTML document and is used to format the layout of web pages.

How to apply CSS
