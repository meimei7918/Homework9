BOM

The window object is supported by all browsers. It represents the browser's window.

  • document: contains all HTML elements of the current page.
  • frames: any frames embedded within the current page.
  • history: contains a stack of sites visited in the current session.
  • location: stores URL of the current page.
  • navigator: stores information about the browser being used, and the OS used by the browser.
  • screen: display properties of the user's computer or device.

JavaScript Conditions- if else and else if

Conditional statements are used to perform different actions based on different conditions.

if (condition1) {
  block of code to be executed if condition1 is true
}
else if (condition2) {
  block of code to be executed if the condition1 is false and condition2 is true
}
else {
  block of code to be executed if the condition1 is false and condition2 is false
}

JavaScript For Loop

for (statement 1; statement 2; statement 3)
{
  code block to be executed // if the code is only a line, you can ignore the {}.
}
  • Statement 1 is executed (one time) before the execution of the code block. → 判斷進入迴圈條件
  • Statement 2 defines the condition for executing the code block. → 終止進入迴圈條件
  • Statement 3 is executed (every time) after the code block has been executed. → 條件在迴圈執行1次後會怎麼變

JavaScript Switch Statement

The switch statement is used to perform different actions based on different conditions.

switch(expression) {
  case x : // x, y can either be numbers or strings
    code block ;
    break ;
  case y :
    code block;
    break ;
  default:
    code block;
}

let year = 1;
let grade;
switch (year) {
  case 1:
    grade = "freshman";
    break;
  case 2:
    grade = "sophomore";
    break;
  default:
    grade = "other";
}

JavaScript Function

A JavaScript function is a block of code designed to perform a particular task.
A JavaScript function is executed when "something" invokes it (calls it).

function name (parameter1, parameter2, parameter3) {
  code to be executed
}
let name = function (parameter1, parameter2, parameter3) {
  code to be executed , e.g.,
  return parameter1+ parameter2 + parameter3;
};
