How to use：Syntax

  • $(selector).action() //methods, functions

    • e.g.,$("p").hide() - hides all <p> elements

Note

  • $ is a function, which means jQuery.
  • $("p").hide(); equals to jQuery("p").hide();

jQuery DOM Manipulation

Changing and manipulating HTML elements and attributes

  • text() - sets or returns the text content of selected elements
  • html() - sets or returns the content of selected elements (including HTML markup)
  • val() - sets or returns the value of form fields
  • attr() – sets or returns attribute values (※)
  • remove()- remove elements with a specified condition

Get contents

  • $(selector).method();

Set contents

  • $(selector).method("set value”);

Add new elements and contents

  • append() - Inserts content at the end of the selected elements
  • prepend() - Inserts content at the beginning of the selected elements
  • after() - Inserts content after the selected elements
  • before() - Inserts content before the selected elements

Remove elements

  • remove():Removes the selected element (and its child elements)

Empty elements

  • empty(): Removes the "child elements" from the selected element

Get and Set CSS Classes

  • addClass()
  • removeClass()
  • toggleClass()
  • css()

jQuery Traversing

jQuery traversing are used to "find" (or select) HTML elements based on their relation to other elements. In the HTML page (DOM tree), you can easily move up (ancestors), down (descendants) and sideways (siblings) in the tree, starting from the selected (current) element.

Traversing Up

  • parent(), parents(), parentsUntil()
  • 特定向上的、全部向上的、向上直到

Traversing Down: 向下

  • children(), find()
  • 特定向下的、向下的

Traversing Sideways: 向兩側找

  • siblings(), next(), nextAll(), nextUntil(), prev(), prevAll(), prevUntil()

Filtering method: 找特定元素

  • The first(), last(), eq()(index from 0), filter() and not()

JavaScript Timing Events

To execute a function or a mission later or at specified time intervals.

  • The setTimeout(function, milliseconds) method calls a function or evaluates an expression after a specified number of milliseconds.
  • The setInterval(function, milliseconds) method is same as setTimeout(), but repeats the execution of the function continuously.
  • 1000 ms = 1 second.
  • Use the clearTimeout() method to prevent the function from running.

Syntax

  • setTimeout(function, milliseconds, param1, param2, ...): 只執行一次(等待指定時間後，只執行一次)
  • setInterval(function, milliseconds, param1, param2, ...): repeat的執行，不會因為中間暫停就不計沒有執行set interval的時間(每隔指定時間，就重複執行一次)
  • Using clearTimeout() to stop a function
