觀念測驗

點選項作答，作答後會顯示解析。

1. typeof null 的結果是？

  1. "null"
  2. "undefined"
  3. "object"
  4. "string"

這是 JavaScript 早期留下的特例，null 的 typeof 是 "object"。講義也特別點出 undefined 和 null 不一樣。

2. "5" === 5 的結果是？

  1. true
  2. false
  3. undefined
  4. 會出錯

=== 連型別一起比，字串和數字型別不同，所以是 false。若用 == 會先轉型，結果是 true。

3. 下面程式最後印出什麼？
let x = 1; { let x = 2; } console.log(x);

  1. 1
  2. 2
  3. undefined
  4. 出錯：x 重複宣告

let 有區塊範圍，大括號裡的 x 是另一個變數，出了大括號就不存在。在不同區塊宣告同名變數是允許的。

4. let a = [1, 2, 3, 4]; a.splice(1, 2); 之後 a 是？

  1. [1, 2]
  2. [1, 4]
  3. [3, 4]
  4. [2, 3]

splice(起始索引, 刪幾個)：從索引 1（數字 2）開始刪 2 個，刪掉 2 和 3，剩下 [1, 4]。

5. 哪一種迴圈「保證至少執行一次」？

  1. for
  2. while
  3. switch
  4. do … while

do while 先執行一次再檢查條件。for 和 while 都是先檢查，條件一開始就不成立時一次都不跑。switch 不是迴圈。

6. Math.floor(Math.random() * 10) 可能產生哪些數？

  1. 1 到 10
  2. 0 到 10
  3. 0 到 9 的整數
  4. 0 到 1 之間的小數

Math.random() 產生 0（含）到 1（不含），乘 10 是 0 到 9.999…，再用 floor 無條件捨去，得到 0 到 9。

7. GeoJSON 裡臺大的座標應該寫成？

  1. [25.0174, 121.5397]
  2. [121.5397, 25.0174]
  3. {"lat": 25.0174, "lng": 121.5397}
  4. "25.0174, 121.5397"

GeoJSON 的座標是 [經度, 緯度] 的陣列，經度在前。這是最常見的錯誤：寫反了點會跑到海上。

8. 變數 data 是一個 FeatureCollection，要取得第一個圖徵的 name 屬性，該怎麼寫？

  1. data.name[0]
  2. data.features.name
  3. data[0].properties.name
  4. data.features[0].properties.name

FeatureCollection → features 陣列 → 第 0 個 Feature → properties 物件 → name。物件用點、陣列用中括號。

1. 成績等第計算器函式、if、事件

做一個輸入框和一個按鈕。按下按鈕時讀取分數，用自己寫的函式 grade(score) 回傳等第（90 以上 A+、80 以上 A、70 以上 B、60 以上 C、其餘 F），把結果顯示在網頁上。分數不是 0–100 的數字時顯示「請輸入 0–100 的分數」。

提示

輸入框的 .value 是字串，先用 Number() 轉成數字；isNaN() 可以判斷轉換失敗。if 要從高分往低分判斷。

參考解答 
<input id="score" type="number" placeholder="分數">
<button onclick="showGrade()">計算</button>
<p id="result"></p>

<script>
  const grade = (score) => {
    if (score >= 90) return "A+";
    else if (score >= 80) return "A";
    else if (score >= 70) return "B";
    else if (score >= 60) return "C";
    else return "F";
  };

  function showGrade() {
    const s = Number(document.getElementById("score").value);
    const out = document.getElementById("result");
    if (isNaN(s) || s < 0 || s > 100) {
      out.innerHTML = "請輸入 0–100 的分數";
    } else {
      out.innerHTML = s + " 分的等第是 " + grade(s);
    }
  }
</script>

2. 一週氣溫統計陣列、for

給定 const temps = [28, 31, 33, 29, 35, 30, 27];（週一到週日），用 for 迴圈算出平均氣溫（取到小數一位）、最高溫，以及超過 30 度的有哪幾天，印在 Console。

提示

準備一個星期名稱的陣列，用同一個索引 i 去對應。小數一位可用 toFixed(1)。

參考解答 
const temps = [28, 31, 33, 29, 35, 30, 27];
const days = ["一", "二", "三", "四", "五", "六", "日"];
let sum = 0;
let max = temps[0];
const hot = [];

for (let i = 0; i < temps.length; i++) {
  sum += temps[i];
  if (temps[i] > max) max = temps[i];
  if (temps[i] > 30) hot.push("週" + days[i]);
}

console.log("平均：" + (sum / temps.length).toFixed(1));   // 平均：30.4
console.log("最高：" + max);                                // 最高：35
console.log("超過 30 度：" + hot.join("、"));                // 超過 30 度：週二、週三、週五

30 度那天（週六）不算「超過」，所以用 > 而不是 >=。

3. 從 GeoJSON 列出地點JSON、DOM

把下面的 GeoJSON 存成變數，用迴圈在網頁上產生一個清單，每一項顯示「名稱（經度, 緯度）」。

const places = {
  "type": "FeatureCollection",
  "features": [
    { "type": "Feature", "properties": { "name": "臺大" },     "geometry": { "type": "Point", "coordinates": [121.5397, 25.0174] } },
    { "type": "Feature", "properties": { "name": "台北 101" }, "geometry": { "type": "Point", "coordinates": [121.5645, 25.0340] } },
    { "type": "Feature", "properties": { "name": "臺北車站" }, "geometry": { "type": "Point", "coordinates": [121.5170, 25.0478] } }
  ]
};
提示

先在 HTML 放一個 <ul id="list">，迴圈裡把每一項的字串加起來，最後一次寫進 innerHTML。coordinates[0] 是經度、[1] 是緯度。

參考解答 
<ul id="list"></ul>
<script>
  // const places = { ... 上面的資料 ... };
  let html = "";
  for (let i = 0; i < places.features.length; i++) {
    const f = places.features[i];
    const [lng, lat] = f.geometry.coordinates;
    html += "<li>" + f.properties.name + "（" + lng + ", " + lat + "）</li>";
  }
  document.getElementById("list").innerHTML = html;
</script>

const [lng, lat] = ... 是陣列解構，等於分別寫 coordinates[0] 和 coordinates[1]。
