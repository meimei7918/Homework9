觀念測驗

點選項作答，作答後會顯示解析。題目依本週四份講義整理。

1. 下列哪一個「不是」講義所說的 GIS 五個組成之一？

  1. 資料
  2. 方法
  3. 人
  4. 網路

五個組成是硬體、軟體、資料、方法、人。網路是 WebGIS 用來溝通的技術，不在 GIS 的基本組成裡。

2. 在講義的 WebGIS 架構中，PHP 程式在哪裡執行？

  1. 使用者的瀏覽器
  2. 伺服器
  3. 資料庫裡
  4. 圖磚服務裡

PHP 是伺服器端語言，在伺服器上執行後把結果傳給瀏覽器。瀏覽器裡跑的是 HTML / CSS / JavaScript。

3. 執行 docker run -i --rm --name example -p 21822:80 example 後，要用哪個網址看網站？

  1. http://localhost:80
  2. http://example:21822
  3. http://localhost:21822
  4. http://localhost/example

-p 21822:80 是「電腦的 21822 對應到容器的 80」，所以在自己的電腦上連 localhost 的 21822 port。

4. Docker 的映像檔（image）和容器（container）的關係，下列何者正確？

  1. 映像檔是範本，容器是用映像檔跑起來的執行個體
  2. 容器是範本，映像檔是執行中的程式
  3. 兩者是同一個東西的不同名稱
  4. 映像檔只能有一個容器

映像檔像食譜（docker build 產生），容器是照食譜做出來、正在執行的那一份（docker run 產生）。同一個映像檔可以跑出很多個容器。

5. 網頁在 https://example.com/course/week1/index.html，裡面寫 <img src="/images/a.jpg">，瀏覽器會去哪裡找圖？

  1. https://example.com/course/week1/images/a.jpg
  2. https://example.com/images/a.jpg
  3. https://example.com/course/images/a.jpg
  4. 電腦的 C:/images/a.jpg

開頭是 / 的路徑從網站根目錄算起。如果要找 week1 底下的 images，應寫 images/a.jpg 或 ./images/a.jpg。

6. 要讓使用者輸入「多行」的意見，最適合用哪個元素？

  1. <input type="text">
  2. <pre>
  3. <textarea>
  4. <select>

textarea 是多行文字輸入框。input type="text" 只有一行；pre 是顯示預先格式化的文字，不能輸入；select 是下拉選單。

7. CSS 選擇器 a#btn1 和 a #btn1 的差別是？

  1. 前者選 id 為 btn1 的 a 元素；後者選 a 裡面 id 為 btn1 的元素
  2. 兩者完全相同
  3. 前者選 a 裡面的元素；後者選 a 本身
  4. 後者是錯誤語法

中間的空格代表「子孫」。沒有空格表示條件寫在同一個元素上。

8. margin: 10px 20px 30px 40px; 的左邊外距是多少？

  1. 10px
  2. 20px
  3. 30px
  4. 40px

四個值的順序是上、右、下、左（順時針），所以左邊是第四個值 40px。

寫一個 HTML 頁面，包含一張表單：姓名（文字）、email、組別（下拉選單：第 1–4 組）、通勤方式（單選：步行、腳踏車、公車、捷運）、有興趣的主題（複選：交通、環境、觀光）、想法（多行文字），最後一個送出按鈕。頁面標題要用 <h1>。

提示

單選的 radio 要用同一個 name 才會互斥；用 <label for="..."> 對應 input 的 id，點文字也能勾選。

參考解答 
<!DOCTYPE html>
<html>

    <meta charset="utf-8">
    <title>期末專題分組調查</title>
  </head>
  <body>
    <h1>期末專題分組調查</h1>
    <form>
      <p><label for="name">姓名</label> <input type="text" id="name" name="name"></p>
      <p><label for="email">Email</label> <input type="email" id="email" name="email"></p>
      <p><label for="group">組別</label>
        <select id="group" name="group">
          <option>第 1 組</option><option>第 2 組</option>
          <option>第 3 組</option><option>第 4 組</option>
        </select></p>
      <p>通勤方式：
        <input type="radio" id="walk" name="commute" value="walk"><label for="walk">步行</label>
        <input type="radio" id="bike" name="commute" value="bike"><label for="bike">腳踏車</label>
        <input type="radio" id="bus" name="commute" value="bus"><label for="bus">公車</label>
        <input type="radio" id="mrt" name="commute" value="mrt"><label for="mrt">捷運</label></p>
      <p>有興趣的主題：
        <input type="checkbox" id="t1" name="topic" value="traffic"><label for="t1">交通</label>
        <input type="checkbox" id="t2" name="topic" value="env"><label for="t2">環境</label>
        <input type="checkbox" id="t3" name="topic" value="tour"><label for="t3">觀光</label></p>
      <p><label for="idea">想法</label><br><textarea id="idea" name="idea" rows="4" cols="40"></textarea></p>
      <input type="submit" value="送出">
    </form>
  </body>
</html>

2. 把 inline style 搬到外部 CSSCSS

下面的頁面把樣式寫在每個元素上。請改成：HTML 裡完全沒有 style 屬性，樣式全部放在 style.css，並用 <link> 引入。兩段說明文字樣式一樣，請用 class 共用。

<h1 style="color:navy;text-align:center;">WebGIS</h1>
<p style="color:gray;font-size:14px;">第一段說明</p>
<p style="color:gray;font-size:14px;">第二段說明</p>
<div style="background-color:powderblue;padding:20px;">重點區塊</div>
提示

h1 只有一個，可以直接用標籤選擇器；重複出現的段落用 class；區塊可以給 id。

參考解答 
<!-- index.html -->
<head>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>WebGIS</h1>
  <p class="desc">第一段說明</p>
  <p class="desc">第二段說明</p>
  <div id="highlight">重點區塊</div>
</body>
/* style.css */
h1 { color: navy; text-align: center; }
.desc { color: gray; font-size: 14px; }
#highlight { background-color: powderblue; padding: 20px; }

3. 響應式三欄Bootstrap

用 Bootstrap 5.3 做一列三個區塊（介紹、地圖、圖表）：手機上每個佔滿一整列，平板（md）兩個一列，電腦（lg）三個並排。

提示

一個元素可以同時有多個 col 類別，例如 col-12 col-md-6。一列總共 12 等分。

參考解答 
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">

<div class="container">
  <div class="row">
    <div class="col-12 col-md-6 col-lg-4">介紹</div>
    <div class="col-12 col-md-6 col-lg-4">地圖</div>
    <div class="col-12 col-md-6 col-lg-4">圖表</div>
  </div>
</div>

12 ÷ 6 = 2 個一列，12 ÷ 4 = 3 個一列。md 時第三個區塊會自動換到下一列。
