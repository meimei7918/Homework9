觀念測驗

點選項作答，作答後會顯示解析。

1. 程式碼沒有任何錯誤訊息，但地圖一片空白。最可能的原因是？

  1. 沒有設定 controls
  2. 沒有寫 minZoom
  3. 地圖的 div 沒有設定高度
  4. 沒有引入 jQuery

div 預設高度是 0，地圖畫在 0 像素高的容器裡就看不到，也不會報錯。要用 CSS 給 #map 高度。

2. 決定地圖「中心點與縮放層級」的是哪個物件？

  1. ol.Map
  2. ol.layer.Tile
  3. ol.source.OSM
  4. ol.View

View 管觀看方式：center、zoom、rotation，以及 minZoom、extent 等限制。Map 負責把 View、Layer、Control 組在一起。

3. 要把臺大（經度 121.5397、緯度 25.0174）設為中心，正確寫法是？

  1. ol.proj.fromLonLat([121.5397, 25.0174])
  2. ol.proj.fromLonLat([25.0174, 121.5397])
  3. [121.5397, 25.0174]
  4. ol.proj.transform([121.5397, 25.0174], "EPSG:3857", "EPSG:4326")

fromLonLat 吃 [經度, 緯度]，轉成 EPSG:3857。直接給經緯度數字會被當成公尺，中心會跑到非洲外海；D 的轉換方向寫反了。

4. 直接複製 OpenLayers 官網範例到 HTML，出現跟 import 有關的錯誤。原因是？

  1. OpenLayers 需要付費
  2. 官網範例是 ES 模組寫法，需要 npm 打包工具編譯
  3. 瀏覽器不支援地圖
  4. 沒有連上網路

官網範例用 import Map from "ol/Map"，要搭配打包工具。課堂改用 CDN 的 ol.js，以 new ol.Map(...) 的全域寫法，或參考不需編譯的 v4.6.5 範例。

5. Google 圖磚網址中的 lyrs=s 代表？

  1. 標準道路圖
  2. 地形圖
  3. 只有衛星影像
  4. 衛星＋道路

m 道路、p 地形＋道路、s 衛星、y 衛星＋道路（混合）、h 只有道路、t 只有地形。

6. ol.control.MousePosition 預設顯示的座標單位是公尺，要改成經緯度該怎麼做？

  1. 把 View 改成 EPSG:4326
  2. 加上 ScaleLine
  3. 改用 ol.source.XYZ
  4. 在 MousePosition 設定 projection: "EPSG:4326"

MousePosition 的 projection 決定顯示用的座標系統，地圖本身仍維持 EPSG:3857。

7. 地圖上同時加了三個底圖，要切換成只顯示其中一個，常用的方法是？

  1. 每次切換都重新建立整個 ol.Map
  2. 對每個底圖呼叫 setVisible()，只有選中的設 true
  3. 改變 View 的 zoom
  4. 刪掉 div 再加回來

範例 map_Basemap.html 就是用迴圈對每個圖層 setVisible(idx == i)。

8. 不想讓使用者把地圖拖離臺灣，應該在哪裡設定？

  1. View 的 extent
  2. Layer 的 opacity
  3. Map 的 target
  4. Source 的 url

View 的 extent 限制中心點能移動的範圍（座標要用 EPSG:3857），搭配 minZoom 就不會縮到看見整個世界。

實作題

三題都從同一份 HTML 開始改，用 CDN 引入 OpenLayers：

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/ol@v10.11.0/ol.css">
<script src="https://cdn.jsdelivr.net/npm/ol@v10.11.0/dist/ol.js"></script>
<style> html, body, #map { margin: 0; height: 100%; } </style>
<div id="map"></div>

1. 以臺大為中心的地圖Map、View

建立一張 OSM 底圖的地圖，中心在臺大（121.5397, 25.0174），縮放層級 15。

提示

地圖要有 target、layers、view 三個設定。中心點記得轉成 EPSG:3857。

參考解答 
const map = new ol.Map({
  target: "map",
  layers: [new ol.layer.Tile({ source: new ol.source.OSM() })],
  view: new ol.View({
    center: ol.proj.fromLonLat([121.5397, 25.0174]),
    zoom: 15
  })
});

2. 只能看臺灣的地圖View 限制

把第 1 題改成：一開始顯示全臺（中心 121, 23.7、zoom 8），最小縮放 7、最大縮放 14，且不能拖出經度 119–123、緯度 21.5–26 的範圍。

提示

extent 的格式是 [最小 x, 最小 y, 最大 x, 最大 y]，要從 EPSG:4326 轉成 EPSG:3857，用 ol.proj.transformExtent。

參考解答 
const taiwan = ol.proj.transformExtent([119, 21.5, 123, 26], "EPSG:4326", "EPSG:3857");

const map = new ol.Map({
  target: "map",
  layers: [new ol.layer.Tile({ source: new ol.source.OSM() })],
  view: new ol.View({
    center: ol.proj.fromLonLat([121, 23.7]),
    zoom: 8,
    minZoom: 7,
    maxZoom: 14,
    extent: taiwan
  })
});

3. 比例尺與滑鼠經緯度Control

在第 2 題的地圖加上縮放按鈕、比例尺，以及在右上角顯示滑鼠所在位置的經緯度（取到小數 5 位，格式像「121.53970, 25.01740」）。

提示

MousePosition 有 coordinateFormat 參數，可以用 ol.coordinate.createStringXY(5)。controls 設定後會取代預設控制項，所以 Zoom 要自己加回來。

參考解答 
const map = new ol.Map({
  target: "map",
  controls: [
    new ol.control.Zoom(),
    new ol.control.ScaleLine(),
    new ol.control.MousePosition({
      projection: "EPSG:4326",
      coordinateFormat: ol.coordinate.createStringXY(5)
    })
  ],
  layers: [new ol.layer.Tile({ source: new ol.source.OSM() })],
  view: new ol.View({ /* 同第 2 題 */ })
});

MousePosition 預設就顯示在右上角（class 為 ol-mouse-position），要換位置可以用 CSS 調整。
