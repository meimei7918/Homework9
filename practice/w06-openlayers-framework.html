觀念測驗

點選項作答，作答後會顯示解析。

1. 在老師的框架裡，「側邊欄開關」的程式應該寫在哪個檔案？

  1. index.html
  2. main.js
  3. map.js
  4. style.css

main.js 負責介面互動（面板、表格、頁面控制）；map.js 負責地圖、圖層與樣式；index.html 是介面骨架並引入所有檔案。

2. 幫「點」圖徵設定樣式，ol.style.Style 裡要用哪個屬性？

  1. image
  2. stroke
  3. fill
  4. text

點用 image，放 ol.style.Circle 或 ol.style.Icon。線用 stroke，面用 stroke 加 fill。

3. 要把線畫成虛線，應設定？

  1. fill: new ol.style.Fill({ dash: true })
  2. width: "dashed"
  3. stroke: new ol.style.Stroke({ lineDash: [4, 8] })
  4. image: new ol.style.Circle({ dash: 4 })

lineDash 是 Stroke 的屬性，陣列代表「畫 4 像素、空 8 像素」反覆。

4. 做點擊 Popup 時，用哪個方法找出被點到的圖徵？

  1. map.getView()
  2. map.addOverlay()
  3. evt.coordinate
  4. map.forEachFeatureAtPixel(evt.pixel, ...)

forEachFeatureAtPixel 依點擊的螢幕像素找圖徵。evt.coordinate 是點擊位置的地圖座標，用來設定 Popup 的位置。

5. 要讓 Popup 關閉，最簡單的寫法是？

  1. map.removeLayer(popup)
  2. popup.setPosition(undefined)
  3. popup.setVisible(false)
  4. 重新整理頁面

Overlay 沒有位置就不會顯示。Overlay 不是圖層，不能用 removeLayer；要移除可以用 map.removeOverlay。

6. 關於 ol.Geolocation，下列何者正確？

  1. 不需要使用者同意就能取得位置
  2. 在 http:// 網站一定可以使用
  3. 需要使用者允許，且網站要是 HTTPS（或 localhost）
  4. 回傳的座標一定是 EPSG:4326

瀏覽器的定位要使用者同意，也只在安全連線下開放。回傳座標的系統由 projection 參數決定，通常設成地圖的 EPSG:3857。

7. 一份 GeoJSON 的座標是 TWD97（EPSG:3826），直接用 new ol.format.GeoJSON() 讀會怎樣？

  1. OpenLayers 會把數字當成經緯度，點的位置完全錯誤；需要用 proj4 定義並註冊 EPSG:3826
  2. 會自動辨識並轉換
  3. 只要把 View 改成 EPSG:3826 就好，不用 proj4
  4. GeoJSON 不能存 TWD97 座標

OpenLayers 內建只認識 4326 與 3857。TWD97 要先 proj4.defs(...)、ol.proj.proj4.register(proj4)，讀檔時指定 dataProjection: "EPSG:3826"。

8. 要讓使用者能「拖動已畫好圖徵的節點」，需要加入哪些互動？

  1. 只要 Draw
  2. Draw 加 Snap
  3. 只要 Overlay
  4. Select 加 Modify

Select 選取圖徵，Modify 讓被選取的圖徵可以拖動節點。Draw 是新增圖徵用的。

實作題

1. 依車站類型上色Style function

在 W06 框架範例的 map.js 中，把捷運站圖層的樣式改成：地下車站藍色、高架車站橘色（屬性欄位是 stype，值為「地下車站」或「高架車站」）。

提示

Vector 圖層的 style 可以是一個函式，OpenLayers 會對每個圖徵呼叫一次，傳入 feature，回傳要用的 Style。先把兩種 Style 建好放在物件裡，不要在函式裡每次 new。

參考解答 
const makeDot = (color) => new ol.style.Style({
  image: new ol.style.Circle({
    radius: 6,
    fill: new ol.style.Fill({ color: color }),
    stroke: new ol.style.Stroke({ color: "#ffffff", width: 2 })
  })
});
const stationStyles = {
  "地下車站": makeDot("#0070bd"),
  "高架車站": makeDot("#e8730c")
};

// 在 layers.metro 的 ol.layer.Vector 設定裡：
style: function (feature) {
  return stationStyles[feature.get("stype")] || makeDot("gray");
}

2. 讀入 TWD97 座標的 GeoJSONproj4

下面的 GeoJSON 座標是 TWD97（EPSG:3826）。存成 twd97.geojson，在 OpenLayers 地圖上正確顯示這三個點。

{ "type": "FeatureCollection", "features": [
  { "type": "Feature", "properties": { "name": "國立臺灣大學" }, "geometry": { "type": "Point", "coordinates": [304470.2, 2767813.3] } },
  { "type": "Feature", "properties": { "name": "台北101" },     "geometry": { "type": "Point", "coordinates": [306965.5, 2769662.2] } },
  { "type": "Feature", "properties": { "name": "臺北車站" },   "geometry": { "type": "Point", "coordinates": [302166.2, 2771171.6] } }
] }
提示

proj4 的定義字串可以在 epsg.io/3826 複製。順序是：引入 proj4.js → proj4.defs → ol.proj.proj4.register(proj4) → 讀檔時指定 dataProjection。

參考解答 
<script src="https://cdn.jsdelivr.net/npm/proj4@2.12.1/dist/proj4.js"></script>
<script src="https://cdn.jsdelivr.net/npm/ol@v10.11.0/dist/ol.js"></script>
<script>
  proj4.defs("EPSG:3826",
    "+proj=tmerc +lat_0=0 +lon_0=121 +k=0.9999 +x_0=250000 +y_0=0 +ellps=GRS80 +units=m +no_defs");
  ol.proj.proj4.register(proj4);

  const points = new ol.layer.Vector({
    source: new ol.source.Vector({
      url: "twd97.geojson",
      format: new ol.format.GeoJSON({
        dataProjection: "EPSG:3826",      // 檔案裡的座標
        featureProjection: "EPSG:3857"    // 地圖顯示的座標
      })
    })
  });

  const map = new ol.Map({
    target: "map",
    layers: [new ol.layer.Tile({ source: new ol.source.OSM() }), points],
    view: new ol.View({ center: ol.proj.fromLonLat([121.54, 25.035]), zoom: 13 })
  });
</script>

三個點應出現在臺大、101、臺北車站。如果點跑到很遠的地方，通常是忘了 register，或 dataProjection 沒設。

3. 幫框架接上繪圖功能，並加上刪除Interaction

W06 範例的 draw.js 已經寫好繪製、編輯、匯出，但 index.html 沒有載入它，也沒有按鈕。請：(1) 在側邊欄加入「畫點／畫線／畫面／編輯／匯出」按鈕；(2) 載入 draw.js；(3) 新增功能：選取圖徵後按 Delete 鍵刪除。

提示

看 draw.js 用了哪些選擇器：.btn-draw 搭配 drawType 屬性、#btn-edit、#btn-json。draw.js 用到 map，所以要在 map.js 之後載入。刪除要拿 Select 互動的 getFeatures()。

參考解答

index.html 的側邊欄（Accordion 裡）加一段：

<h3>繪圖工具</h3>
<div>
  <button class="btn btn-default btn-draw" drawType="Point">畫點</button>
  <button class="btn btn-default btn-draw" drawType="LineString">畫線</button>
  <button class="btn btn-default btn-draw" drawType="Polygon">畫面</button>
  <button class="btn btn-default" id="btn-edit">編輯</button>
  <a class="btn btn-default" id="btn-json">匯出 GeoJSON</a>
</div>

body 最後，在 map.js 之後加：

<script src="./js/map.js"></script>
<script src="./js/main.js"></script>
<script src="./js/draw.js"></script>

在 draw.js 的 $('#btn-edit').click(...) 之後加上刪除功能（select_interaction 是 draw.js 裡原本的變數）：

document.addEventListener("keydown", function (e) {
  if (e.key !== "Delete" && e.key !== "Backspace") return;
  if (!select_interaction) return;               // 沒有在編輯模式
  const selected = select_interaction.getFeatures();
  selected.forEach(function (f) {
    if (drawSource.hasFeature(f)) drawSource.removeFeature(f);  // 只刪自己畫的
  });
  selected.clear();
});

加上 hasFeature 判斷，是因為 Select 也能選到捷運站等其他圖層的圖徵，不應該刪到它們。Mac 筆電鍵盤的刪除鍵是 Backspace，所以兩個都接受。
