觀念測驗

點選項作答，作答後會顯示解析。

1. $(function () { ... }); 的作用是？

  1. 宣告一個叫 $ 的函式
  2. 等文件載入完成後才執行裡面的程式
  3. 立刻執行，不管元素是否存在
  4. 等所有圖片下載完才執行

它是 $(document).ready(...) 的簡寫，DOM 建好就執行，避免選不到元素。等圖片全部載入的是 window 的 load 事件。

2. $(".layer") 選到的是？

  1. id 為 layer 的元素
  2. 所有 <layer> 標籤
  3. 所有 class 含 layer 的元素
  4. name 為 layer 的表單欄位

jQuery 選擇器沿用 CSS：點是 class、井號是 id、沒有符號是標籤名。

3. $("#box").append("<p>新</p>") 和 $("#box").after("<p>新</p>") 的差別？

  1. append 加在 #box 裡面的最後；after 加在 #box 外面、緊接在它之後
  2. 兩者相同
  3. append 加在外面；after 加在裡面
  4. after 會取代 #box

append / prepend 作用在元素「裡面」，after / before 作用在元素「外面」。

4. 想清空清單 <ul id="todo"> 裡所有項目，但保留 ul 本身，該用？

  1. $("#todo").remove()
  2. $("#todo").hide()
  3. $("#todo").text()
  4. $("#todo").empty()

empty() 只刪除子元素；remove() 連 ul 本身一起刪掉；hide() 只是看不見，項目還在。

5. 要讀取 <input id="city"> 使用者輸入的文字，用哪個方法？

  1. $("#city").text()
  2. $("#city").html()
  3. $("#city").val()
  4. $("#city").attr("text")

表單欄位的值用 val()。text() 和 html() 讀的是元素「之間」的內容，input 沒有內容。

6. children() 和 find() 的差別？

  1. 沒有差別
  2. children 只找下一層；find 會找所有層的子孫
  3. children 找所有子孫；find 只找下一層
  4. find 往上找祖先

children() 只看直接的子元素；find() 往下搜尋所有層級，通常要給選擇器，例如 find("li")。

7. 每 1 秒更新一次時鐘，並在按下按鈕時停止，應該用？

  1. setInterval 搭配 clearInterval
  2. setTimeout 搭配 clearInterval
  3. setInterval 搭配 stop()
  4. for 迴圈跑 1000 次

setInterval 會重複執行，回傳的編號交給 clearInterval 停止。setTimeout 只執行一次；stop() 是停止 jQuery 動畫。

8. 關於 HTTP 的 GET，下列何者正確？

  1. 資料放在請求的 body 裡
  2. 適合傳送密碼
  3. 只能由表單發出
  4. 資料以查詢字串附在網址後面，例如 ?id=3

GET 把參數放在網址上，看得到也會被記錄，不適合傳密碼；POST 才把資料放在 body。AJAX 也能發 GET。

實作題

1. 待辦清單事件、append、toggleClass

一個輸入框、一個「新增」按鈕、一個「全部清除」按鈕和一個清單。按新增時把輸入的文字加成新的項目並清空輸入框（空白不加）；點某個項目時切換刪除線；按全部清除時清空清單。

提示

新增的項目是之後才產生的，直接 $("li").click() 綁不到，要用事件委派：$("#list").on("click", "li", ...)。刪除線可以用一個 class 搭配 text-decoration: line-through。

參考解答 
<style> .done { text-decoration: line-through; color: gray; } </style>
<input id="task"> <button id="add">新增</button> <button id="clear">全部清除</button>
<ul id="list"></ul>

<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
<script>
  $(function () {
    $("#add").click(function () {
      const text = $("#task").val().trim();
      if (text === "") return;
      $("#list").append($("<li>").text(text));   // 用 text() 放入，避免使用者輸入被當成 HTML
      $("#task").val("");
    });
    $("#list").on("click", "li", function () {
      $(this).toggleClass("done");
    });
    $("#clear").click(function () {
      $("#list").empty();
    });
  });
</script>

2. 十秒倒數setInterval

按「開始」後畫面從 10 倒數到 0，每秒減 1；到 0 時顯示「時間到」並停止。倒數中再按開始不應該出現兩個計時器同時跑。

提示

把 setInterval 回傳的編號存在外層變數；開始前先 clearInterval 一次。

參考解答 
<button id="start">開始</button> <span id="count">10</span>

<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
<script>
  $(function () {
    let timer = null;
    $("#start").click(function () {
      clearInterval(timer);              // 避免重複的計時器
      let n = 10;
      $("#count").text(n);
      timer = setInterval(function () {
        n--;
        if (n <= 0) {
          clearInterval(timer);
          $("#count").text("時間到");
        } else {
          $("#count").text(n);
        }
      }, 1000);
    });
  });
</script>

3. 用 AJAX 讀捷運站資料做成表格$.getJSON

從 W05 範例包下載 metro.geojson 放在練習檔旁邊，用 $.getJSON 讀進來，把每一站的 name、stype、lat、lng 做成表格，表格上方顯示「共 N 站」。

提示

$.getJSON(網址, function (data) { ... }) 是 $.ajax 的簡寫。直接雙擊 HTML 打開時讀檔會被瀏覽器擋，要在資料夾執行 python3 -m http.server 或用 VS Code 的 Live Server。

參考解答 
<p id="total"></p>
<table border="1">
  <thead><tr><th>站名</th><th>類型</th><th>緯度</th><th>經度</th></tr></thead>
  <tbody id="rows"></tbody>
</table>

<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
<script>
  $(function () {
    $.getJSON("metro.geojson", function (data) {
      $("#total").text("共 " + data.features.length + " 站");
      $.each(data.features, function (i, f) {
        const p = f.properties;
        $("#rows").append(
          $("<tr>").append(
            $("<td>").text(p.name), $("<td>").text(p.stype),
            $("<td>").text(p.lat),  $("<td>").text(p.lng)
          )
        );
      });
    }).fail(function () {
      $("#total").text("讀取失敗：請確認是用本機伺服器開啟，且 metro.geojson 在同一個資料夾");
    });
  });
</script>
