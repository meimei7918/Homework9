  • 能分辨 PHP 的區域、全域、static 變數，以及和 JavaScript 變數範圍的差別

PHP 是什麼、怎麼執行

PHPPHP: Hypertext Preprocessor 是一種伺服器端的程式語言。前幾週的 HTML、CSS、JavaScript 都是瀏覽器下載後在使用者電腦上執行；PHP 則是在伺服器上先跑完，再把「結果」（通常是 HTML）送給瀏覽器。

  1. 瀏覽器向網頁伺服器（例如 Apache）要求一個 .php 檔
  2. 伺服器交給 PHP 執行，程式可以讀檔、查資料庫、算資料
  3. 執行結果組成網頁回傳，瀏覽器只看得到結果，看不到 PHP 原始碼

一個 .php 檔裡可以混合 HTML、CSS、JavaScript 和 PHP。只有包在 <?php … ?> 之間的部分會被當成 PHP 執行，其他內容原樣輸出。課程使用 PHP 8.5。

<!DOCTYPE html>
<html><body>
<?php
  echo "The first PHP script!";
?>
</body></html>

用 Docker 建立執行環境

老師的做法是用官方的 php:8.5-cli 映像檔，把 src/ 裡的程式複製進容器，再用 PHP 內建的開發用伺服器 php -S 0.0.0.0:80 提供網頁。另外用 custom.ini 調整 PHP 設定：

設定作用
short_open_tag=On允許用 <? 取代 <?php（短標籤）
display_errors=On把錯誤訊息直接顯示在輸出裡，方便除錯
error_reporting=E_ALL & ~E_NOTICE & …回報所有錯誤，但排除提示（notice）、嚴格模式與「已過時」類的訊息

不開網頁，也可以在容器的命令列直接執行：

docker run -it --rm --name example -p 20080:80 phptest bash   # 進入容器
php -v                     # 查看 PHP 版本
php -q showtime.php        # 執行程式，-q 表示不輸出 HTTP 標頭

短標籤要伺服器開啟 short_open_tag 才能用，換一台伺服器可能就失效。自己寫程式時建議一律寫完整的 <?php。

語法、變數與變數範圍

  • 每個敘述以分號 ; 結尾；註解和 JavaScript 一樣用 // 與 /* */
  • echo 輸出字串；exit 立刻結束整支程式，後面的程式碼都不會執行
  • 變數前面一定要加 $，例如 $x = 10;，不用事先宣告型別
  • 字串用 . 串接，例如 "WebGIS " . $x . " is fun"（JavaScript 是用 +）
  • 變數名稱以英文字母或底線開頭，大小寫有別；$_POST、$_GET 等保留名稱不能拿來用

PHP 的變數範圍

種類說明
區域（local）在函式裡宣告，只能在該函式內使用
全域（global）在函式外宣告，函式裡預設看不到；要在函式內用，必須先寫 global $c;
$GLOBALS存放所有全域變數的陣列，在函式裡可以用 $GLOBALS['f'] 讀取
static只存在函式內，但函式結束後值會保留，下次呼叫時接著用

對照 JavaScript 的變數範圍

JavaScript 只有區域與全域兩種，而且函式裡可以直接讀到外面的全域變數，這點和 PHP 相反。另外，在函式裡對一個沒有宣告過的變數賦值（例如 m = 400;），它會自動變成全域變數。

「沒宣告就自動變全域」只發生在非嚴格模式。加上 "use strict"; 或使用 ES module 時，這樣寫會直接丟出 ReferenceError；養成用 let／const 宣告的習慣比較安全。

流程控制與陣列

if／elseif／else、switch、for、while、do…while 的寫法和 JavaScript 幾乎一樣；注意 PHP 的「否則如果」寫成一個字 elseif。

陣列用 [] 或 array() 建立，分成三種：

種類例子
索引陣列Indexed array$cars = ["Volvo", "BMW", "Toyota"];，索引從 0 開始
關聯陣列Associative array$age = ["Peter" => 35, "Ben" => 37];，用名稱當鍵，類似 JavaScript 的物件
多維陣列陣列裡再放陣列，例如 [["Peter", 35, 175], ["Ben", 37, 180]]
函式用途
array_push($cars, "Benz", "Porsche")在尾端加入一個或多個值；也可以寫 $cars[] = "Benz";
count($a)／count($a, 1)元素個數；第二個參數為 1 時連內層陣列的元素一起算
is_array($a)是不是陣列，常在加入資料前先檢查
in_array("Subaru", $cars)某個值在不在陣列裡
sort()／rsort()由小到大／由大到小排序，可指定 SORT_NUMERIC、SORT_STRING

foreach 專門用來走訪陣列，可以只取值，也可以同時取鍵和值：

foreach ($age as $key => $item) {
  echo "key:{$key} and age:{$item}\n";   // 雙引號字串裡可以用 {$變數} 直接嵌入
}

字串與陣列互轉

  • explode(" ", "Learning WebGIS is fun")：依分隔字元把字串切成陣列

JSON 與超全域變數

讀取 JSON 的步驟：

  1. file_get_contents("shelter.json") 讀進整個檔案（也可以放網址）
  2. json_decode($str, 1) 轉成 PHP 陣列；第二個參數不給的話會變成物件
  3. 用 foreach 取出需要的欄位

反過來，json_encode($array) 把陣列轉成 JSON 字串。索引陣列會變成 JSON 陣列 [...]，關聯陣列變成 JSON 物件 {...}。中文預設會被轉成 喜美 這種跳脫碼，加上 JSON_UNESCAPED_UNICODE 才會保留中文；JSON_PRETTY_PRINT 會排版縮排。這兩個常數的值是 256 和 128，所以講義中寫成 json_encode($cars, 384) 效果相同。

檔案處理與上傳

函式用途
file_exists()檢查檔案是否存在
fopen($file, 模式)／fclose()開啟／關閉檔案。模式 r 讀、w 寫（清空重寫，不存在就建立）、a 附加在最後；加 + 表示可讀也可寫
fgets()／fgetc()／fread()讀一行／讀一個字元／讀指定長度
feof()是否讀到檔案結尾，常寫成 while (!feof($f))
fwrite()寫入內容
file_get_contents()／file_put_contents()一次讀完／一次寫完整個檔案，不需要 fopen 和 fclose，最常用

中文 CSV 常是 Big5 編碼，直接輸出到 UTF-8 網頁會變亂碼，可以用 mb_convert_encoding($str, "UTF-8", "big5") 轉碼。函式前面加 @（例如 @file_get_contents()）可以隱藏警告訊息，再自行判斷回傳值是不是 false。

講義最後補充了 ASCIIAmerican Standard Code for Information Interchange：7 位元、共 128 個字元，包含數字、大小寫英文字母與一些符號和控制字元。範例 showtime.php 用 chr(7) 輸出的就是 ASCII 第 7 號「響鈴」控制字元。

上傳檔案的流程

  1. 確認 php.ini 的 file_uploads = On
  2. HTML 表單要寫 enctype="multipart/form-data" 和 method="post"，裡面放 <input type="file" name="fileX">
  3. 伺服器先把檔案存成暫存檔，PHP 用 move_uploaded_file($_FILES['fileX']['tmp_name'], 目的地) 搬到要放的地方
  4. 檢查同名檔案是否已存在
  5. 視需要限制檔案大小、類型等

$_FILES['fileX'] 裡有 name（原檔名）、type（檔案類型）、size（位元組）、tmp_name（伺服器上的暫存檔名）、error（錯誤代碼）。

直接用使用者上傳的原檔名存檔有安全風險：對方可以上傳 .php 檔，再從網址執行它。正式系統要限制副檔名、改用自己產生的檔名。

AJAX、HTTP 方法與 CORS

W03 學過的 jQuery AJAX（$.ajax()、$.get()、$.getJSON() 等）可以在背景向伺服器要資料、不重新整理整頁。這週的伺服器端就是 PHP。

GETPOST
資料放在哪網址後面的查詢字串（?demo=1&b=2）HTTP 請求的內容（body）
書籤、快取、瀏覽紀錄可以加入書籤、會被快取、會留在瀏覽紀錄都不會
長度與資料類型有長度限制，只能是 ASCII 字元沒有限制，可以傳二進位資料
適合查詢資料新增、修改資料；密碼等敏感資料不要用 GET

其他 HTTP 方法還有 PUT、HEAD、DELETE、PATCH、OPTIONS、CONNECT、TRACE。

老師的兩個範例：網頁用 $.ajax() 以 POST 送出 data: {id: 123}，同時網址帶著 ?demo=1&b=2。PHP 端用 print_r($_GET, 1) 和 print_r($_POST, 1) 把收到的資料印回去，或用 json_encode() 包成 JSON，前端設定 dataType: 'json' 後就能用 result.GET.demo 取值。

為什麼會被 CORS 擋下

瀏覽器有同源政策Same-origin policy：網頁裡的 JavaScript 只能向「同一個來源」要資料。協定、網域、連接埠三者都相同才算同源：

和 https://chiaoling.com/index.php 比較結果
https://chiaoling.com/a.php同源
http://chiaoling.com/不同源（協定不同）
https://demo.chiaoling.com/不同源（網域不同）
https://chiaoling.com:20080/不同源（連接埠不同）

跨來源要資料時，對方伺服器的回應必須帶有 Access-Control-Allow-Origin 標頭，瀏覽器才肯把資料交給你的程式，否則 Console 會出現「blocked by CORS policy」。這就是跨來源資源共用CORS, Cross-Origin Resource Sharing。講義舉了臺南市交通開放資料與一個收發器資料網址當例子，從自己的網頁直接 AJAX 都會被擋。

講義的標題寫成「CROS」、「same original」，正確名稱是 CORS 和 same origin（同源）。

兩種解法

  1. 伺服器開放：如果資料來源是自己的 PHP，在輸出前加一行 header('Access-Control-Allow-Origin: *');（* 表示任何來源都可以，也可以只寫特定網址）。
  2. 用 PHP 當代理：別人的伺服器沒辦法改，就讓自己的 PHP 去抓。CORS 只限制瀏覽器，伺服器之間的請求不受影響。網頁再向自己的 PHP 要資料，就變成同源了。
<?php
header('Access-Control-Allow-Origin: *');
$s = file_get_contents("https://（外部資料網址）");    // 由伺服器去抓
if ($s !== false) {
  $data = json_decode($s, 1);
  if (json_last_error() === JSON_ERROR_NONE) {
    header('Content-Type: application/json; charset=utf-8');
    echo json_encode($data, 384);                      // 384 = 中文不跳脫＋排版
  }
} else {
  header('500 Internal Server Error', true, 500);
}

小結

PHP 在伺服器上執行，瀏覽器只收到結果；變數一律加 $，函式裡要用全域變數必須寫 global。陣列加上 foreach、json_decode／json_encode、file_get_contents 是處理資料最常用的組合。AJAX 被 CORS 擋下時，可以讓自己的伺服器加上 Access-Control-Allow-Origin 標頭，或用 PHP 代為抓取外部資料。
