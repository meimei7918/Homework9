學習目標

  • 能說明 JavaScript 如何透過 DOM 改變網頁內容與樣式
  • 能正確使用 let / const、陣列方法、if / for / while / switch 與函式
  • 能用事件呼叫自己寫的函式
  • 能讀懂 JSON 與 GeoJSON 的結構，並取出裡面的值

JavaScript 在網頁裡的角色

JavaScript 是在瀏覽器裡執行的程式語言（用戶端語言）。它能改 HTML 內容、屬性值、CSS 樣式，靠的是兩個模型：

  • 文件物件模型DOM：網頁內容的物件樹，例如 document.getElementById("abc")
  • 瀏覽器物件模型BOM：以 window 為首，底下有 document、history（瀏覽紀錄）、location（目前網址，例如 window.location.hostname）、navigator（瀏覽器與作業系統資訊）、screen（螢幕資訊）

放 JavaScript 的三個位置

  1. 寫在 <head> 的 <script> 裡
  2. 寫成外部 .js 檔，用 <script src="..."> 引入
  3. 寫在 <body> 的 <script> 裡

放在 head 的程式執行時，body 的元素還沒產生，用 getElementById 會拿到 null。要嘛放到 body 最後，要嘛等文件載入完再執行（下週的 jQuery 會用 document ready 解決）。

除錯時最常用 console.log()，在瀏覽器開發者工具的 Console 面板看結果。

變數

宣告變數有三個關鍵字：var（1998–2015 的舊寫法）、let 與 const（2015 起）。const 宣告後不能重新指定。

let x = 10;
let m, n;
let z = "WebGIS" + " " + "is fun";
const PI = 3.14159;

let 的三個規則：有區塊範圍（只在 { } 內有效）、要先宣告才能用、同一範圍內不能重複宣告。

命名規則：開頭只能是字母、_ 或 $，不能是數字；大小寫有別；不能用保留字（如 let、class、return）。

資料型別與 typeof

變數可以放數字、字串、物件、函式、undefined 等。用 typeof 查型別時有幾個容易混淆的地方：

let t1 = "";         // typeof → "string"（空字串不是 undefined）
let t2 = undefined;  // typeof → "undefined"（還沒被指定任何東西）
let t3 = null;       // typeof → "object"（語言的歷史包袱）

運算子

算術 + - * / % **、指定 = += -=、比較 == === != !== > <、邏輯 && || !。

== 會先轉型再比（"5" == 5 是 true），=== 連型別一起比（"5" === 5 是 false）。一律用 === 比較安全。

陣列

let tArray = ["a", "b", "c"];
let mixed = [0, 1, "abc", { a: 1, b: 2 }];  // 可以混放不同型別
tArray[0];             // "a"，索引從 0 開始
tArray.length;         // 3
tArray.push("d");      // 加到最後
tArray.pop();          // 移除最後一個
tArray.splice(1, 1);   // 從索引 1 開始刪 1 個
tArray.sort();         // 排序（字串）
tArray.reverse();      // 反轉

流程控制

if / else if / else

if (score >= 80) { grade = "A"; }
else if (score >= 60) { grade = "B"; }
else { grade = "C"; }

for、while、do while

for (let i = 0; i < 5; i++) { ... }   // 初始 → 條件 → 每輪結束後執行
while (i < 5) { ...; i++; }            // 條件成立才執行，可能一次都不跑
do { ...; i++; } while (i < 5);        // 先跑一次再檢查，至少跑一次

switch

switch (city) {
  case "Taipei":  msg = "臺北"; break;
  case "Tainan":  msg = "臺南"; break;
  default:        msg = "其他";
}

忘了 break 會「掉到」下一個 case 繼續執行。另外 switch 用 === 比較，表單取得的值是字串，case 1 對不到 "1"，範例 js_switch_select.html 就是這個陷阱。

函式

函式是一段完成特定工作的程式碼，被呼叫時才執行。同一個函式有四種寫法：

function abc(a1) { return a1 + 1; }          // 宣告式
const abc = function (a1) { return a1 + 1; }; // 函式運算式（用 const 比 let 安全）
const abc = (a1) => { return a1 + 1; };       // 箭頭函式
const abc = (a1) => a1 + 1;                   // 只有一行時可省略大括號與 return

產生 0–9 的隨機整數：Math.floor(Math.random() * 10)。Math.random() 回傳 0（含）到 1（不含）之間的數。

事件

事件是瀏覽器或使用者做的事（點擊、輸入、載入完成）。用「事件＋事件處理函式」讓網頁回應：

<button onclick="alert('May I help you?')">按我</button>
<button onclick="gradeFunction(100)">算等第</button>
<button onclick="funcA(); funcB();">一次呼叫兩個</button>

JSON 與 GeoJSON

JSONJavaScript Object Notation 是輕量、跨語言的資料交換格式，副檔名 .json。結構只有兩種：物件 {"key": value} 與陣列 [ ... ]，兩者可以互相巢狀。在 JavaScript 裡解析後就是一般物件。

講義用政府開放資料的「展覽資訊」示範：下載 JSON → 在 Chrome 打開看結構 → 用 JavaScript 取值。

GeoJSONGeoJSON 是描述地理資料的 JSON 開放標準，支援 Point、LineString、Polygon、MultiPoint、MultiLineString、MultiPolygon。副檔名可用 .json，建議用 .geojson。

{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": { "name": "臺大" },
      "geometry": { "type": "Point", "coordinates": [121.5397, 25.0174] }
    }
  ]
}

GeoJSON 的座標順序是 [經度, 緯度]（EPSG:4326），和口語的「緯度、經度」相反。

可以到 geojson.io 在地圖上畫圖形，右邊會即時顯示對應的 GeoJSON。

小結

JavaScript 透過 DOM 改網頁。用 let / const 宣告變數，用 === 比較，陣列索引從 0 開始。函式可以寫成箭頭函式，事件負責呼叫它。JSON 是資料格式，GeoJSON 是加上幾何的 JSON，座標經度在前。
