學習目標

  • 能用三種方式套用 CSS，並說明規則衝突時誰優先
  • 能寫出選擇器搭配 id、class，並分辨 a#btn1 與 a #btn1
  • 能用 margin、padding、position 調整版面
  • 能用 Bootstrap 的格線做出在手機與電腦都好看的版面

CSS 是什麼、怎麼套用

層疊樣式表CSS 描述 HTML 文件「長什麼樣子」，負責顏色、字型、版面。套用方式有三種：

方式寫在哪例子
行內樣式 inline元素的 style 屬性<img style="width:600px;">
內部樣式表 internal<head> 裡的 <style>body {background-color: powderblue;}
外部樣式表 external獨立的 .css 檔，用 <link> 引入<link rel="stylesheet" href="style.css">

<link> 的 rel 是 relationship，說明這個外部檔案和本文件的關係。

常用屬性與顏色

行內樣式的寫法是 style="屬性:值;"。最常用的有 background-color、color、font-family、font-size、text-align。

顏色可以寫成名稱（tomato）、RGB、RGBA（多一個透明度）、HEX（#ff6347）、HSL、HSLA。配色時可以用講義推薦的配色工具。

語法、id 與 class

/* 選擇器 { 屬性: 值; } */
h1 { color: navy; font-size: 32px; }
#header { background: #eee; }     /* id：整頁唯一 */
.note { color: gray; }             /* class：可以重複使用，一個元素可有多個 class */

選擇器的空格有意義

  • a#btn1：id 是 btn1 的那個 <a>（同一個元素）
  • a #btn1：在 <a> 裡面、id 是 btn1 的元素（子孫）

盒模型：margin 與 padding

每個元素都是一個盒子，由內到外是：內容 → 內距padding → 邊框 → 外距margin。margin 是邊框外的空間，padding 是邊框內的空間。

margin: 20px 150px 100px 80px;   /* 上 右 下 左，順時針 */

position 定位

值行為
static（預設）照正常排版，top / left 等無效
relative相對於自己原本的位置偏移，原位置仍保留
fixed相對於視窗固定，捲動也不動
absolute相對於最近一個「非 static」的祖先；沒有的話相對於 body
sticky捲到指定位置前像 relative，之後像 fixed 黏住

元素重疊時，用 z-index 決定誰在上面，數字大的在上，可以是負數。

最常見的組合是父元素 relative、子元素 absolute，讓子元素以父元素為基準定位。WebGIS 裡把按鈕疊在地圖上就是這樣做的。

規則衝突時誰贏

講義列出的優先順序（由高到低）：行內樣式 → 內部樣式表 → 匯入的樣式表 → 外部連結樣式表 → 瀏覽器預設。若權重相同，後寫的規則會蓋掉前面的。

嚴格來說，內部和外部樣式表的權重其實一樣，誰在 HTML 裡比較後面誰贏；真正決定勝負的是選擇器的權重（specificity）：id > class > 標籤。講義的課外閱讀 CSS Specificity 有完整說明。

響應式設計與 Bootstrap

響應式網頁設計RWD 讓同一個網頁在手機、平板、電腦上都好看。BootstrapBootstrap 5.3 是最常用的 RWD 框架，用 CDN 引入 CSS 和 JS 即可：

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>

格線系統

一列最多分 12 欄，結構是 .container → .row → .col。

<div class="container">
  <div class="row">
    <div class="col-md-4">左</div>   <!-- 中螢幕以上佔 4/12 -->
    <div class="col-md-8">右</div>
  </div>
</div>

講義依 W3Schools 整理的斷點：xs（手機，未滿 768px）、sm（平板，768px 以上）、md（小筆電，992px 以上）、lg（桌機，1200px 以上）。

上面的斷點是 Bootstrap 3 的數字。Bootstrap 5 的斷點是 sm 576、md 768、lg 992、xl 1200、xxl 1400px。課堂用 5.3 版時，以官方文件的數字為準。

Bootstrap 官網的範例集和元件頁可以直接複製來改。

快速調樣式的技巧

在 Chrome 開發者工具的檢查面板，可以直接修改元素的樣式並即時看到結果，調到滿意再抄回 CSS 檔。

小結

CSS 有行內、內部、外部三種套用方式，正式專案用外部樣式表。版面靠盒模型（margin / padding）與 position；衝突看權重，同權重後者勝。要支援手機，用 Bootstrap 的 container / row / col 格線。
