學習目標

  • 能說出 WebGIS 專案裡 index.html、map.js、main.js 的分工
  • 能用 ol.style.Style 為點、線、面設定樣式
  • 能用 Overlay 做出點擊圖徵後彈出資訊的 Popup，並用 Geolocation 取得使用者位置
  • 能用 proj4 讀入 TWD97 資料，並實作繪製、編輯、刪除圖徵

用框架搭 WebGIS 介面

做一個完整的 WebGIS 網站，流程是：

  1. 用 Bootstrap 框架做響應式版面
  2. 設計使用者介面（導覽列、側邊欄、圖層清單）
  3. 把程式分成三個檔案
檔案負責
index.html初始介面，引入所有 JS 與 CSS
map.js建立地圖、動態加入圖層、樣式
main.js介面互動：面板開關、表格、頁面控制

側邊欄用 jQuery UI 的 手風琴Accordion 元件，一次只展開一個區塊。

地圖物件要在 document ready 之前就建立好，因為 ready 裡面的程式（例如切換底圖）會用到它。範例把 map.js 放在 <div id="map"> 之後載入，就是為了這件事。

動態加入圖層

範例把所有圖層寫在一個 layers 物件裡，每個圖層有標題、類型（base 底圖或 overlay 疊加）與 OpenLayers 圖層本身。initLayers() 跑一次迴圈：底圖產生單選鈕，疊加圖層產生勾選框，同時把圖層加進地圖。

let layers = {
  OSM:   { title: "OpenStreetMap", type: "base",    layer: new ol.layer.Tile({ source: new ol.source.OSM() }) },
  metro: { title: "捷運站",         type: "overlay", layer: new ol.layer.Vector({
            source: new ol.source.Vector({ url: "./data/metro.geojson", format: new ol.format.GeoJSON() }) }) }
};

好處是要加新圖層只要在 layers 裡多寫一筆，選單會自動長出來。

樣式

用 new ol.style.Style({...}) 設定樣式，點、線、面用的屬性不同：

幾何用什麼例子
點image：ol.style.Circle 或 ol.style.Icon半徑 7 的黑點加紅框；或用圖示網址
線stroke：ol.style.Stroke顏色、寬度、lineDash: [4, 8] 虛線
面stroke ＋ fill：ol.style.Fill半透明藍色填色 rgba(0,0,255,0.3)
 
new ol.style.Style({
  image: new ol.style.Circle({
    radius: 7,
    fill: new ol.style.Fill({ color: "black" }),
    stroke: new ol.style.Stroke({ color: [255, 0, 0], width: 2 })
  })
});

顏色可以寫字串、rgba()，或 [R, G, B] 陣列。

Overlay 與 Popup

Overlayol.Overlay 是把一個 HTML 元素「釘」在地圖上某個座標，地圖移動時跟著動。做法：

  1. 宣告 new ol.Overlay({ element: ... })
  2. 設定位置 overlay.setPosition(座標)
  3. map.addOverlay(overlay)

做 Popup 就是在點擊事件裡找出被點到的圖徵，再把它的屬性塞進 Overlay：

map.on("click", function (evt) {
  const feature = map.forEachFeatureAtPixel(evt.pixel, (f) => f);
  if (feature) {
    popupEl.innerHTML = feature.get("name");
    popup.setPosition(evt.coordinate);
  } else {
    popup.setPosition(undefined);   // 點到空白處就關閉
  }
});

定位

取得裝置位置可以做定位服務，例如災害通知。網站要經過使用者同意才能取得位置。OpenLayers 用 ol.Geolocation：

const geolocation = new ol.Geolocation({
  tracking: true,
  projection: map.getView().getProjection()
});
geolocation.on("change:position", function () {
  const pos = geolocation.getPosition();   // EPSG:3857
  map.getView().setCenter(pos);
});

瀏覽器只在 HTTPS（或 localhost）下允許定位，GitHub Pages 是 HTTPS，所以可以用。

不同座標系統的資料

OpenLayers 以 EPSG:3857 顯示，但能直接讀 EPSG:4326 的 GeoJSON（它會自動轉）。如果資料是 TWD97（EPSG:3826），OpenLayers 不認識，就要：

  1. 在 index.html 引入 proj4.js
  2. 定義座標系統：proj4.defs("EPSG:3826", "+proj=tmerc +lat_0=0 +lon_0=121 +k=0.9999 +x_0=250000 +y_0=0 +ellps=GRS80 +units=m +no_defs")
  3. 註冊到 OpenLayers：ol.proj.proj4.register(proj4)
  4. 讀 GeoJSON 時指定來源座標：new ol.format.GeoJSON({ dataProjection: "EPSG:3826", featureProjection: "EPSG:3857" })；有些情況要對每個圖徵手動轉換

讀入 GeoJSON

用 ol.source.Vector 加上 url 與 format: new ol.format.GeoJSON()，就能從伺服器載入 GeoJSON。注意瀏覽器的同源限制：從別的網域讀檔，對方伺服器要允許 CORS，否則要放在自己的網站或透過 proxy。

繪製、編輯、刪除圖徵

繪製

  1. 建立暫存圖層：ol.layer.Vector 加空的 ol.source.Vector（可設樣式）
  2. map.addLayer() 把它加進地圖
  3. 建立 ol.interaction.Draw，指定 source 與 type（Point、LineString、Polygon）
  4. map.addInteraction()

編輯

  1. 建立 ol.interaction.Select（選取）
  2. 建立 ol.interaction.Modify（修改節點）
  3. 兩個都用 map.addInteraction() 加入

刪除

先用 Select 選到圖徵，再用 document.addEventListener("keydown", ...) 監聽鍵盤，按下 Delete 時從 source 移除選到的圖徵：

document.addEventListener("keydown", function (e) {
  if (e.key === "Delete") {
    select.getFeatures().forEach((f) => drawSource.removeFeature(f));
    select.getFeatures().clear();
  }
});

講義用的是舊式的 keyCode（Delete 是 46），現代寫法用 e.key 比較好讀。

小結

WebGIS 網站分成 index.html（介面）、map.js（地圖與圖層）、main.js（互動）。樣式用 Style 的 image / stroke / fill。Popup＝點擊事件找圖徵＋Overlay。TWD97 資料要用 proj4 定義並註冊。繪圖用 Draw，編輯用 Select＋Modify，刪除用 Select＋鍵盤事件。
