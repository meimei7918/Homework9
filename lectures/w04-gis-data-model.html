從 GIS 設計看資料模型

GIS 系統的生命週期是：需求調查 → 資料模型 → 系統分析 → 系統設計 → 系統實作 → 系統維護。資料模型在很前面就要決定，因為它決定了資料庫怎麼存、之後能做什麼分析。

WebGIS 依功能深淺可以分三級：

  • 基本：提供資訊、辨識，例如查詢、套疊
  • 中階：操作與分析，例如 GIS 操作、空間分析、統計分析
  • 進階：策略、建議、知識分享

網格與向量

空間資料傳統上分成兩大類，兩者互轉（向量轉網格叫網格化，網格轉向量叫向量化）一直是麻煩的問題。

網格raster向量vector
結構由像素（pixel）排成的陣列，用行列編號定位，每格存一個值點是一組座標；線是一串線段；面由邊界線圍成
點、線、面怎麼表示一格、一串相鄰格、一群相連格座標、座標序列、封閉邊界
種類連續（例如高程）、離散（例如土地利用分類）點、線、面
優點結構簡單，適合連續變化的現象只存關心的點，省空間
缺點檔案大，精度受網格大小限制假設邊界是硬的，和現實常常不符（例如土壤、植被漸變）
常見格式GeoTIFF、grd、ASCII GridShapefile、GeoJSON、KML

數值地形模型

  • 數值地形模型DTM：統稱，包含下面兩種
  • 數值高程模型DEM：裸露地表，不含植物、建物
  • 數值地表模型DSM：包含植物、建物的表面

內政部的 20 公尺網格 DTM 是規則網格，用 .hdr（標頭，說明範圍與網格大小）加 .grd（資料）兩個檔案；講義也示範了 30 公尺 DEM。

Shapefile

ESRI Shapefile 是二進位格式，不是文字檔；一個圖層只能有一種幾何類型（點、線或面）。它其實是一組同名檔案：

  • .shp：幾何
  • .shx：幾何的索引
  • .dbf：屬性表

傳 Shapefile 給別人時要整組一起傳（通常還有 .prj 記錄座標系統），只給 .shp 對方打不開屬性。

臺灣常用座標系統

在 QGIS 處理向量資料

加入既有的向量檔

Layer → Add Layer → Add Vector Layer，選 .shp（或 All files）。講義範例是臺北市路邊停車格位。加入後可以開屬性表檢視或修改。

加入 CSV

Layer → Add Layer → Add Delimited Text Layer，指定哪一欄是 X（經度）、哪一欄是 Y（緯度），以及座標系統。

自己建立資料

Layer → Create Layer → New Shapefile Layer，設定幾何類型與欄位 → 開啟編輯（Toggle editing）→ 新增多邊形圖徵，例如描出一棟建物。

轉成 GeoJSON 或其他座標系統

在圖層上按右鍵 Export → Save Features As，格式選 GeoJSON，座標系統可以順便改（網頁用通常選 EPSG:4326）。

同一個 GeoJSON 裡同時有點和面時，在 QGIS 匯入要指定要載入哪一種幾何類型。

小結

網格用格子存值，適合連續現象；向量用座標存點線面，省空間但邊界是硬的。Shapefile 是一組檔案，GeoJSON 是單一文字檔。臺灣資料多半是 TWD97（EPSG:3826），網頁地圖顯示用 Web Mercator（EPSG:3857），交換資料用 WGS84（EPSG:4326）。
