學習目標

  • 在空白網頁裡用 Leaflet 建出一張可以拖曳縮放的地圖
  • 分清楚 Map、Layer、Control 三種物件
  • 知道怎麼接上臺灣國土測繪中心的 WMTS 底圖

最小可執行的地圖

LeafletLeaflet.js 是輕量的開源地圖函式庫。要讓它跑起來只需要三樣東西：CSS、JS、一個有高度的 div。

<link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css">
<script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>

<div id="map" style="height: 400px"></div>
<script>
  const map = L.map("map").setView([25.04, 121.54], 13);
  L.tileLayer("https://tile.openstreetmap.org/{z}/{x}/{y}.png", {
    attribution: "&copy; OpenStreetMap contributors"
  }).addTo(map);
</script>

div 一定要有高度，否則地圖高度是 0，畫面一片空白但也不會報錯。

三種核心物件

物件是什麼例子
L.map畫布本身，管理中心點與縮放setView、fitBounds、on("click")
Layer疊在地圖上的東西L.tileLayer、L.marker、L.geoJSON
Control浮在角落的介面元件L.control.layers、L.control.scale

幾乎所有東西都是「建立物件 → .addTo(map)」這個模式。

座標順序：[緯度, 經度]

Leaflet 的 setView、L.marker 都吃 [lat, lng]，也就是緯度在前。臺北大約是 [25.04, 121.54]。

GeoJSON 剛好相反，是 [lng, lat]。兩個混用時最容易把點畫到印度洋去。

臺灣的 WMTS 底圖

國土測繪中心提供 網路地圖圖磚服務WMTS，其中 GoogleMapsCompatible 的切法與 Leaflet 相容，可以直接用 L.tileLayer 接：

// 臺灣通用電子地圖（注意網址裡是 {y}/{x}）
L.tileLayer("https://wmts.nlsc.gov.tw/wmts/EMAP/default/GoogleMapsCompatible/{z}/{y}/{x}", {
  attribution: "&copy; 內政部國土測繪中心",
  maxZoom: 19
});

把 EMAP 換成 PHOTO2 就是正射影像。實際的切換範例見本週程式碼頁。

小結

Leaflet 的一切都是 Map ＋ Layer ＋ Control。座標記住「Leaflet 緯度先、GeoJSON 經度先」。底圖只要有 {z}/{x}/{y} 網址就能接。
