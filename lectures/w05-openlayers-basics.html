學習目標

  • 能說明 WebGIS 的定義與優點
  • 能用 CDN 引入 OpenLayers，寫出 Map、Layer、Source、View 組成的最小地圖
  • 能接上 OSM、Google 與國土測繪中心 WMTS 底圖並切換
  • 能加入控制項，並用 View 限制縮放與範圍

再談 WebGIS

WebGIS 是至少包含一個伺服器與一個用戶端的資訊系統：伺服器是 GIS 伺服器，用戶端是瀏覽器或手機 App。簡單說，任何用網路技術讓伺服器和用戶端溝通的 GIS 都算 WebGIS。

優點：觸及全球、使用者多、跨平台、平均每位使用者的成本低、容易使用、統一更新、應用多元。

OpenLayers 與版本問題

OpenLayersol 是開源的 JavaScript 地圖函式庫，可以顯示來自任何來源的圖磚、向量資料與標記。目前版本 10.x，官網有兩百多個範例（動畫、繪圖、群聚、選取、Popup、圖層捲簾、熱區圖、標籤等）。

官網範例是用 ES6 的 import 寫的，需要打包工具（npm）編譯；直接貼到 HTML 會出現「不支援 import」的錯誤。課堂做法是用 CDN 引入完整版 ol.js，以 ol.Map、ol.layer.Tile 這種「全域 ol 物件」的寫法；老師也建議參考 v4.6.5 的範例原始碼，因為那一版不需要編譯。

OpenLayers 支援的資料格式：GeoJSON、KML、GML、WKTWell-Known Text（例如 POINT(121.5 25.0)）、GeoRSS、GPX 等。

建立地圖需要三樣東西

  1. 引入 OpenLayers 的 JS 與 CSS（CDN 或下載到本機）
  2. 一個地圖容器：<div id="map"></div>，要給它高度
  3. 建立地圖的 JavaScript
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/ol@v10.11.0/ol.css">
<script src="https://cdn.jsdelivr.net/npm/ol@v10.11.0/dist/ol.js"></script>

<div id="map" style="height: 400px"></div>
<script>
  const map = new ol.Map({
    target: "map",                                 // 掛到哪個 div
    layers: [
      new ol.layer.Tile({ source: new ol.source.OSM() })
    ],
    view: new ol.View({
      center: ol.proj.fromLonLat([121.54, 25.02]), // 經度, 緯度 → EPSG:3857
      zoom: 12
    })
  });
</script>

四個核心物件

物件是什麼例子
ol.Map地圖本身，用 target 綁定 divmap.addLayer()、map.on("click")
Layer圖層，分 Image、Tile、Vector 三種ol.layer.Tile、ol.layer.Vector
Source圖層的資料來源，每個圖層都要有一個ol.source.OSM、ol.source.XYZ、ol.source.WMTS、ol.source.Vector
ol.View觀看方式：中心點、縮放（或解析度）、旋轉center、zoom、minZoom、extent

OpenLayers 預設以 EPSG:3857 顯示，所以經緯度要先轉換：ol.proj.transform([lng, lat], "EPSG:4326", "EPSG:3857") 或簡寫 ol.proj.fromLonLat([lng, lat])。順序都是經度在前。

底圖

XYZ 圖磚（Google、OSM）

new ol.layer.Tile({
  source: new ol.source.XYZ({
    url: "https://mt{0-3}.google.com/vt/lyrs=m&x={x}&y={y}&z={z}"
  })
});

mt{0-3} 讓請求分散到 mt0 到 mt3 四台伺服器。lyrs 決定 Google 圖層種類：

lyrs圖層lyrs圖層
m標準道路圖s只有衛星影像
h只有道路t只有地形
p地形＋道路y衛星＋道路（混合）
r改版道路圖

直接用 Google 圖磚網址不符合 Google 的服務條款，課堂練習可以，正式上線的專題建議改用 OSM 或國土測繪中心圖磚。

國土測繪中心 WMTS

用 ol.source.WMTS 時要自己定義圖磚格網：以 EPSG:3857 的範圍為基準，算出每一層的解析度（resolutions）與層級編號（matrixIds），再填入圖層名稱，例如 EMAP（臺灣通用電子地圖）、PHOTO2（正射影像）。範例包的 map_Basemap.html 有完整寫法。

多個底圖時，把它們都加進地圖，再用 layer.setVisible(true / false) 控制只顯示其中一個。

控制項

控制項是浮在地圖上的介面元件：

  • ol.control.Zoom：放大縮小按鈕
  • ol.control.ZoomSlider：縮放滑桿
  • ol.control.ScaleLine：比例尺
  • ol.control.MousePosition：滑鼠位置座標，可以設 projection: "EPSG:4326" 顯示經緯度
  • ol.control.OverviewMap：鷹眼圖
const map = new ol.Map({
  target: "map",
  controls: [new ol.control.Zoom(), new ol.control.ScaleLine()],
  layers: [...],
  view: ...
});

用 View 固定範圍

不希望使用者把地圖拖到太遠或縮得太小，可以在 View 設：

new ol.View({
  center: ol.proj.fromLonLat([121, 23.7]),
  zoom: 8,
  minZoom: 7,
  maxZoom: 14,
  extent: ol.proj.transformExtent([119, 21.5, 123, 26], "EPSG:4326", "EPSG:3857")
});

小結

OpenLayers 地圖＝Map 綁 div，加上 Layer（每個都有 Source）與 View。顯示座標是 EPSG:3857，經緯度要先轉。底圖可以是 XYZ 或 WMTS，多底圖用 setVisible 切換。控制項加在 controls，範圍限制寫在 View。
