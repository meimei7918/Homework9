學習目標

  • 能寫出一份 HTML5 文件的完整骨架
  • 能說明瀏覽器怎麼把 HTML 變成 DOM 樹
  • 能正確使用連結、圖片（含相對路徑）、表格、清單、表單等元素

HTML 是什麼

超文本標記語言HTML 是描述網頁「結構」的標記語言。內容用標籤包起來，瀏覽器不會顯示標籤本身，而是依標籤決定怎麼呈現內容。副檔名是 .html 或 .htm，目前的版本是 HTML5（持續更新的 living standard）。

網頁的流程是：瀏覽器向網頁伺服器（例如 Apache）發出 HTTP 請求，伺服器回傳 HTML，瀏覽器再把它畫出來。

文件骨架

<!DOCTYPE html>          <!-- 宣告這是 HTML5 -->
<html>                   <!-- 根元素 -->
  <head>                 <!-- 給瀏覽器看的資訊 -->
    <title>網頁標題</title>
  </head>
  <body>                 <!-- 畫面上看得到的內容 -->
    ...
  </body>
</html>
  • 元素可以巢狀；寫法是 <元素 屬性="值">內容</元素>
  • 標籤名稱不分大小寫（但習慣寫小寫）
  • 註解寫成 <!-- ... -->

DOM：瀏覽器眼中的 HTML

網頁載入後，瀏覽器會把 HTML 轉成一棵物件樹，叫 文件物件模型DOM，它是 W3C 的標準。之後 JavaScript 與 jQuery 就是透過這棵樹去「找到、修改、新增、刪除」元素。

在 Chrome 按右鍵 →「檢查」看到的 Elements 面板，就是 DOM 樹。

常用元素

標題、分隔線、換行

<h1> 到 <h6> 是六級標題；<hr/> 是主題分隔（通常畫成一條橫線）；<br/> 是換行。

連結

<a href="https://www.geog.ntu.edu.tw/" title="滑過時的提示" target="_blank">臺大地理系</a>
target開在哪裡
_self（預設）目前分頁
_blank新分頁或新視窗
_parent / _top上一層框架 / 整個視窗
框架名稱指定名稱的框架

書籤：先給元素一個 id，例如 <p id="s1">，再用 <a href="#s1"> 跳過去。

圖片與檔案路徑

<img src="DeptGeography.jpg" alt="臺大地理系" style="width:600px;height:450px;" />

alt 是圖片載不出來時顯示的替代文字，也給螢幕閱讀器使用。大小可以用 style，也可以用 width / height 屬性（可寫百分比）。

src 寫法指向
pic.jpg和目前網頁同一個資料夾
images/pic.jpg 或 ./images/pic.jpg目前資料夾底下的 images（兩種寫法相同）
/images/pic.jpg網站根目錄底下的 images
../pic.jpg上一層資料夾

以 / 開頭的路徑是從網站根目錄算起。網站如果放在子路徑（像 GitHub Pages 的 /repo名稱/），這種路徑就會找錯地方。

表格與清單

表格：<table> 裡用 <tr> 分列，<th> 是表頭格、<td> 是一般格。

清單：無序清單 <ul>（符號可用 list-style-type 改成 disc、circle、square、none）；有序清單 <ol>，type 屬性可設 1、A、a、I、i，start 設起始數字。項目都用 <li>。

表單

<form> 用來收集使用者輸入，裡面常用：

  • <input>：靠 type 決定樣子，例如 text、password、radio、checkbox、submit、reset、button、color、date、datetime-local、email、file、month、number
  • <select>：下拉選單
  • <textarea>：多行文字

span、p、pre、div

  • <span>：把一小段行內文字包起來
  • <p>：段落
  • <pre>：預先格式化的文字，空白與換行都原樣保留
  • <div>：區塊容器，排版時最常用

文字格式

b 粗體、strong 重要、i 斜體、em 強調、mark 標記、small 小字、del 刪除、ins 插入、sub 下標、sup 上標。b / i 只是外觀，strong / em 帶有語意。

head 裡放什麼

元素用途
<title>文件標題，必填
<style>這一頁專用的樣式
<link>連結外部樣式表
<meta>字元編碼、描述、關鍵字、作者等
<script>用戶端的 JavaScript

想知道某個元素有哪些屬性，查 W3Schools 的 HTML Attribute Reference（講義標註為練習）。

小結

HTML 負責結構，瀏覽器把它變成 DOM 樹，之後的 CSS 與 JavaScript 都作用在這棵樹上。寫圖片和連結時特別注意相對路徑：沒有開頭、./、../、/ 指的是不同位置。
