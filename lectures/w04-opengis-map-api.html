學習目標

  • 能說明 OSM 的三種幾何元素與 key=value 標籤，並用 Overpass turbo 下載資料
  • 能分辨 WMS、WFS、WMTS 回傳的東西
  • 能解釋圖磚的 z / x / y、影像金字塔，以及 XYZ 和 TMS 的差別
  • 能依需求選擇地圖 API，並知道 Turf.js 與 openrouteservice 能做什麼

OpenStreetMap

OpenStreetMapOSM 是 2004 年成立、由志工共同編修的開放地理資料庫，屬於自願式地理資訊VGI。

  • 圖徵由三種幾何元素組成：node（點）、way（線或面）、relation（元素之間的關係，選用）
  • 屬性用 key=value 的標籤表示，例如 building=yes、amenity=school
  • 每一次協作編輯都有紀錄

取得 OSM 資料

  • Overpass turbo：網頁版的 OSM 資料探勘工具。設定查詢標籤（例如 building=*）→ 執行 → Export 成 GeoJSON
  • Geofabrik：依國家、區域下載整份 OSM 資料庫
  • 標籤的意思查 OSM Wiki 的 Key descriptions

海德堡大學的 HeiGIT 也以 OSM 為基礎做研究與工具，openrouteservice 就是他們開發的。

OGC 與 OpenGIS 標準

開放地理空間協會OGC 成立於 1994 年，由五百多個企業、政府、研究機構與大學組成，目標是讓地理資訊與服務 FAIR：可被找到、可存取、可互通、可重複使用。

為什麼重要？資料來源有商用、開源各種格式，只要大家都照 OGC 的標準提供服務，任何用戶端都能透過網路取用。三個最常見的服務標準：

標準回傳什麼發布
WMSWeb Map Service已經畫好、有地理參考的地圖圖片（JPEG、PNG）2006
WFSWeb Feature Service向量圖徵本身（點、線、面＋屬性）2005
WMTSWeb Map Tile Service預先切好的圖磚，以固定比例尺排成金字塔2010

WMTS 是為了大量使用、高擴充性而設計：用戶端需要多少範圍就要多少張圖磚。

圖磚

XYZ 與 TMS

XYZ 是 Google Maps 和 OSM 採用的規則，網址長得像 .../{z}/{x}/{y}.png：z 是縮放層級，x、y 是圖磚編號。

OSM：        https://tile.openstreetmap.org/{z}/{x}/{y}.png
Google 道路： https://mt0.google.com/vt/lyrs=m&x={x}&y={y}&z={z}

TMS（Tile Map Service）是 OSGeo 制定的規格，和 XYZ 唯一的差別是 y 軸方向相反：XYZ 的 y 從上往下數，TMS 從下往上數。

影像金字塔

  • 每張圖磚 256 × 256 像素
  • 縮放層級 0 到 23；z = 0 時整個世界只有 1 張圖磚
  • 每放大一級，邊長變 2 倍、張數變 4 倍：z = 1 是 2 × 2 = 4 張，編號 (0,0)、(1,0)、(0,1)、(1,1)

第 z 層一邊有 2z 張圖磚，總共 4z 張。x 從左（經度 −180°）往右數，y 從上（北）往下數。

向量圖磚

向量圖磚和網格圖磚一樣分層切塊，但每塊裝的是向量資料（GeoJSON、TopoJSON、Mapbox Vector Tile），所以樣式可以在用戶端調整。Google 的 Styling Wizard 就是在調向量地圖的樣式；QGIS 可用 Vector Tiles Reader 外掛讀取。

在 QGIS 加入 WMTS

Layer → Add Layer → Add WMS/WMTS Layer，新增連線，網址填國土測繪中心的 https://maps.nlsc.gov.tw/S_Maps/wmts，就能選臺灣通用電子地圖等圖層。

Map API

地圖應用程式介面Map API 讓開發者把互動地圖、地理資料與定位功能嵌進網站或 App。講義把它分成三類：

繪圖與視覺化

API特色費用
OpenLayers完全免費開源，功能最完整（本課使用）免費
Leaflet輕量、外掛多、上手快免費
MapLibre GL JS用 WebGL 渲染向量圖磚；2020 年 12 月從 Mapbox 分支免費
Mapbox GL JS向量圖磚與樣式需 token，依用量計費

ArcGIS Maps SDK for JavaScript串 ArcGIS 生態系需 token，依用量計費

空間分析與功能

  • Turf.js：在瀏覽器做 GIS 運算與空間分析。引入 js 後直接呼叫，例如 turf.buffer(point, 500, {units: "meters"}) 做環域
  • 路徑規劃：openrouteservice、Google Routes API
  • 地理編碼（地址轉座標）：Nominatim、Google Geocoding API、Mapbox geocoding

openrouteservice

由海德堡地理資訊技術研究所開發，以 OSM 為基礎的開源服務，提供路徑規劃（Directions）、等時圈Isochrones（例如走路 10 分鐘能到的範圍）、高程等 API。

小結

OSM 是志工共編的開放資料，用 Overpass turbo 下載。OGC 標準讓不同來源互通：WMS 給圖片、WFS 給圖徵、WMTS 給圖磚。圖磚以 z/x/y 編號，每層張數乘 4，TMS 的 y 軸和 XYZ 相反。地圖 API 選免費的 OpenLayers 或 Leaflet 就夠用，分析交給 Turf.js。
