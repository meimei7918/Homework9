WebGIS 的三層架構

網路地理資訊系統WebGIS 就是把 GIS 的「看圖、查詢、分析」搬到瀏覽器上。可以拆成三層來想：

層負責什麼常見工具
前端（瀏覽器）畫地圖、處理使用者互動Leaflet、OpenLayers、MapLibre GL
地圖服務把資料變成圖磚或 API 提供出去GeoServer、WMTS / WMS、向量圖磚服務
資料層存放與查詢空間資料PostGIS、GeoJSON 檔、Shapefile

這門課前半段幾乎都在「前端」這一層：資料先用靜態 GeoJSON 檔，地圖服務直接用公開的圖磚。

圖磚：網路地圖的切法

一次把整張世界地圖傳給瀏覽器太大了，所以網路地圖會把每個縮放層級切成 256×256 像素的 圖磚Tile，網址通常長這樣：

https://tile.openstreetmap.org/{z}/{x}/{y}.png
  • z：縮放層級，0 是整個世界一張圖，每加 1 級邊長加倍、張數變 4 倍
  • x、y：該層級裡第幾欄、第幾列

瀏覽器只下載畫面範圍內的那幾張，所以拖曳、縮放才會順。

三種一定會遇到的座標系統

座標參考系統CRS 決定「一組數字代表地球上哪個位置」。每個系統都有一個 EPSG 代碼EPSG code 當身分證。

代碼名稱單位什麼時候用
EPSG:4326WGS84 經緯度度GPS、GeoJSON 標準、資料交換
EPSG:3857Web Mercator公尺幾乎所有網路底圖的「顯示」座標
EPSG:3826TWD97 / TM2 (121°)公尺臺灣政府開放資料、量測面積距離

Web Mercator 越往高緯度面積放大越誇張，不能拿來算面積。要算臺灣的面積或距離，先轉成 TWD97。

好消息是 Leaflet 預設已經幫我們處理：我們給它 WGS84 經緯度，它自己投影成 Web Mercator 畫出來。

小結

WebGIS ＝ 前端畫圖 ＋ 服務供圖 ＋ 資料庫存資料。底圖是切好的圖磚；資料用 EPSG:4326 存，用 EPSG:3857 顯示，用 EPSG:3826 計算。
