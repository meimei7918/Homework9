GIS 的定義與五個組成

課本對 地理資訊系統GIS 的定義可以拆成一句話：以電腦為基礎，處理「有地理位置的資料」的資訊系統，從擷取、建模、儲存、查詢、分享、操作、分析一路到呈現。

GIS 不只是軟體，它由五個部分組成：

  • 硬體：電腦、伺服器、GPS 等設備
  • 軟體：QGIS、ArcGIS，或我們要自己寫的網頁
  • 資料：有座標的資料加上它的屬性
  • 方法：分析流程與演算法
  • 人：設計、使用與維護系統的人

WebGIS 的架構

網路地理資訊系統WebGIS 就是用網路技術讓「伺服器」和「瀏覽器」溝通的 GIS。整體可以分成三段，資料從右往左流：

位置做什麼本課會用到的技術
用戶端（瀏覽器）畫地圖、處理使用者操作、送出請求HTML / CSS / JavaScript，地圖 API：OpenLayers、Leaflet、Google Maps API
伺服器接收請求、執行伺服器端程式、回傳結果Apache 等網頁伺服器，PHP 等伺服器端語言
資料與服務存放資料、提供底圖與統計等服務MySQL、PostgreSQL 等資料庫；WMS、WFS、圖磚服務

原始資料要先經過前處理再匯入資料庫；現成的外部資源（例如政府的圖磚服務、別人的 API）也可以直接被伺服器或瀏覽器呼叫。

WebGIS 的實例

講義列了很多可以直接打開來玩的例子（連結都整理在最下面的「外部資源」），大致可以分成幾類：

  • 通用地圖：Google Maps
  • 即時資料：空氣品質、Windy 氣象、北市好停車、YouBike 站點
  • 政府圖資平台：新北 iMAP、臺北市歷史圖資、實價登錄、水保署 BigGIS、海域整合資訊
  • 研究應用：死亡率地圖、全面攻蚊、直覺式導航、從 Flickr 照片找熱門地點（POI / ROI）、地址語意連結、SiniGIS 時空資訊平台
  • 有趣的互動：Radio Garden、台灣自然聲音地圖

歷屆學長姐的期末專題也很多元：路殺地圖、公投概況地圖、國道車流量、租屋地圖、長照服務平台、校園登革熱孳生源紀錄、雲林旅遊網等。

期末專題可以從政府資料開放平臺找資料起頭。先想「誰會用、要解決什麼問題」，再決定要放哪些圖層。

小結

GIS 是處理地理參考資料的資訊系統，由硬體、軟體、資料、方法、人組成。WebGIS 把它搬上網路，分成瀏覽器、伺服器、資料服務三段。這門課先學前端，再學後端，最後做一個四人一組的 WebGIS 專題。
