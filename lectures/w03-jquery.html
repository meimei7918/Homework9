學習目標

  • 能引入 jQuery 並用 $(selector).action() 選取與操作元素
  • 能分辨 text / html / val / attr 的取值與設值，以及 append / prepend / after / before
  • 能用 DOM 走訪方法從一個元素找到它的父、子、兄弟元素
  • 能說明 GET 與 POST 的差別，並用 AJAX 在不重新整理頁面的情況下載入資料

jQuery 是什麼、怎麼引入

jQuery 是一個 JavaScript 函式庫，把「找元素、改內容、處理事件、做動畫、AJAX」包成簡短又跨瀏覽器的寫法。引入有兩種方式：

  • 下載 jQuery 檔案放在專案裡，當本機檔引入
  • 從 CDNContent Delivery Network 引入。CDN 是分散在各地的一群伺服器，使用者會從較近的節點下載

找網址的方式：jquery.com → Download → releases.jquery.com → 選版本的 minified。

基本語法與 document ready

$("p").hide();        // 隱藏所有 <p>
$(".test").hide();    // 隱藏所有 class="test"
$("#test").hide();    // 隱藏 id="test"

$ 就是 jQuery 這個函式，$("p") 等於 jQuery("p")。

$(function () {
  // 文件載入完成後才執行，等同 $(document).ready(function () { ... });
});

沒有包在 document ready 裡、又寫在元素之前的程式會找不到元素，所以「沒反應」。範例 jq_jquery2.html 就是這個反例。

選擇器與事件

jQuery 選擇器建立在 CSS 選擇器上，另外加了自己的語法，例如 :first、:even、[href$='.pdf']。

常用事件：滑鼠的 click、dblclick、mouseenter、mouseleave；鍵盤的 keypress、keydown、keyup；表單的 submit、change、focus、blur；文件與視窗的 load、resize、scroll。

$("#btn").click(function () { ... });
$("p").on({                         // on() 一次綁多個事件
  mouseenter: function () { $(this).css("background", "lightgray"); },
  mouseleave: function () { $(this).css("background", "white"); }
});

特效

類別方法
顯示隱藏hide、show、toggle
滑動slideDown、slideUp、slideToggle
淡入淡出fadeIn、fadeOut、fadeToggle、fadeTo(速度, 透明度)
自訂動畫animate({CSS 屬性}, 速度, callback)
停止stop(stopAll, goToEnd)

大多數特效可以帶「速度」和「完成後要做的事（callback）」兩個參數，例如 $("#b1").hide(100)。

DOM 操作（講義標註重要）

取值與設值

方法處理的東西
text()純文字內容
html()內容，包含 HTML 標籤
val()表單欄位的值
attr()屬性值，例如 attr("href")

不帶參數是取值：$("#name").val()；帶參數是設值：$("#name").val("Kuo")。

新增、刪除、清空

  • append / prepend：加在選取元素裡面的最後 / 最前
  • after / before：加在選取元素外面的後面 / 前面
  • remove()：連同自己和子元素一起刪掉
  • empty()：只清空子元素，自己留著

class 與 CSS

addClass、removeClass、toggleClass 切換 class；css("color") 取樣式、css("color", "red") 設樣式。

DOM 走訪

從目前元素出發，在 DOM 樹上往上、往下、往旁邊找元素：

方向方法
往上（祖先）parent()、parents()、parentsUntil()
往下（子孫）children()（只找下一層）、find()（所有層）
同層（兄弟）siblings()、next()、nextAll()、nextUntil()、prev() 系列
篩選first()、last()、eq(索引，從 0 起)、filter()、not()

日期與計時器

Date 物件處理日期時間。計時器：

const t = setTimeout(fn, 1000);   // 1 秒後執行一次
const r = setInterval(fn, 1000);  // 每 1 秒執行一次
clearTimeout(t);                  // 取消
clearInterval(r);                 // 停止重複

1000 毫秒 = 1 秒。

jQuery UI 與圖表

jQuery UI 是建立在 jQuery 上的介面元件集，例如 Datepicker、Autocomplete、Slider、Dialog、Progressbar，第六週的側邊欄還會用到 Accordion。

資料要做成圖表時，講義介紹四個函式庫：Highcharts、D3.js、Chart.js、Google Charts，範例包都有對應的 demo。

HTTP 方法與 AJAX

HTTP 是用戶端與伺服器之間「請求－回應」的協定。最常用的兩個方法：

GETPOST
用途向伺服器要資料送資料給伺服器，新增或更新資源
資料放哪網址後面的查詢字串（?a=1&b=2）請求的 body

其他還有 PUT、HEAD、DELETE、PATCH、OPTIONS 等。

AJAXAsynchronous JavaScript and XML 是在背景向伺服器要資料、拿到後只更新頁面的一部分，不用整頁重新載入。

$.ajax({
  url: "ajax001.php?demo=1&b=2",
  type: "GET",
  success: function (data) { console.log(data); },
  error: function () { console.log("ajax error"); }
});

AJAX 範例需要 PHP 伺服器回應，第七週學 PHP 後就能自己寫 ajax001.php 這一端。

小結

jQuery 的一切都是 $(選擇器).動作()，程式包在 document ready 裡。取值不帶參數、設值帶參數；append 加在裡面、after 加在外面。走訪讓你從一個元素找到相關元素。AJAX 讓網頁不重新整理就能和伺服器交換資料。
