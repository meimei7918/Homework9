這段程式在做什麼

把第二週講義的觀念拼起來：一張以臺北為中心的地圖，右上角可以在 OpenStreetMap、臺灣通用電子地圖、正射影像之間切換，左下角有比例尺。點地圖任何地方，會跳出該點的經緯度。

逐段解說

1. 建立地圖

L.map("map") 綁定 id 為 map 的 div，setView([緯度, 經度], 縮放) 決定一開始看到哪裡。

2–3. 底圖與切換控制項

每個底圖都是一個 L.tileLayer，但只有 OSM 先 addTo(map)。L.control.layers 的第一個參數是「底圖」物件，同一時間只會顯示一個（單選），物件的 key 就是選單上顯示的文字。

國土測繪中心的網址是 {z}/{y}/{x}，和 OSM 的 {z}/{x}/{y} 順序不同，寫反會整片空白。

6. 點擊事件

map.on("click", handler) 的事件物件裡有 e.latlng。用 L.popup().setLatLng().setContent().openOn(map) 在點擊處彈出一個不綁定任何標記的 popup。

map.on("click", (e) => {
  const { lat, lng } = e.latlng;
  L.popup().setLatLng(e.latlng)
    .setContent(`緯度 ${lat.toFixed(5)}`)
    .openOn(map);
});

練習

  • 把 PHOTO2 換成國土測繪中心的其他圖層（例如 EMAP2）
  • 點擊時除了 popup，也在地圖上留下一個 L.circleMarker
  • 用 L.control.layers 的第二個參數加一個可勾選的疊加圖層
