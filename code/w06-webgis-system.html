這包範例在做什麼

這是老師 11/19 上課發的 WebGIS 展示系統，是 W06 framework 範例的延伸版。介面一樣是導覽列、左側圖層面板和地圖，這一版把上次「寫好但沒接上」的功能都接起來了：

  • 繪圖：側邊欄新增「繪圖」區塊並載入 draw.js，可以畫點、線、面，編輯節點，下載成 GeoJSON。
  • 刪除：按住 Alt（Mac 是 Option）點選圖徵，再按 Delete 鍵刪除。
  • 資訊表：點機場捷運站會跳出一個表格，顯示名稱、經緯度、車站類型。
  • 新資料與座標轉換：新增台北捷運站與自行車租借站；自行車站的座標是 TWD97（EPSG:3826），靠 proj4 轉換才能放對位置。
  • 樣式生效：上一版被註解掉的 setStyle 打開了，捷運站、捷運線、縣市界都用自訂樣式。

用到 OpenLayers 10.2.1、proj4、jQuery＋jQuery UI、Bootstrap 3。建議閱讀順序：src/index.html → src/js/map.js → src/js/draw.js → src/js/main.js。最外層的 Dockerfile 是老師在自己電腦上架伺服器用的，網站上用不到。

內嵌框比較窄，建議按「新分頁開啟」看完整介面：先按導覽列的「圖層列表」打開側邊欄，勾選套疊圖資，再展開「繪圖」試試。原始碼裡以 【說明】 開頭的註解是 AI 逐段加上的中文解說，程式本身沒有因此改變。

範例檔案

重點解說

map.js 開頭：用 proj4 讓 OpenLayers 認得 TWD97

proj4.defs('EPSG:3826', "+title=二度分帶：TWD97 TM2 台灣 +proj=tmerc +lat_0=0 +lon_0=121 +k=0.9999 +x_0=250000 +y_0=0 +ellps=GRS80 +units=公尺 +no_defs");
proj4.defs('urn:ogc:def:crs:EPSG::3826', proj4.defs('EPSG:3826'));
ol.proj.proj4.register(proj4);

bike.geojson 的檔頭寫著 "crs": {"properties": {"name": "urn:ogc:def:crs:EPSG::3826"}}，座標像 [296599.9, 2779290.4]（公尺）。註冊之後，OpenLayers 讀檔時會自動把它從 EPSG:3826 轉成地圖用的 EPSG:3857。實際執行確認：關渡水岸公園轉換後是經度 121.4621、緯度 25.1213，位置正確。

老師把單位寫成 +units=公尺。proj4 不認得這個字，會改用預設的公尺，所以結果剛好正確；正式寫法是 +units=m。

map.js：點擊跳出資訊表（ol.Overlay）

map.on('singleclick', function(evt) {
  let feature = map.forEachFeatureAtPixel(evt.pixel, function(feature, layer) { return feature; });
  if (typeof(popup) != undefined) { map.removeOverlay(popup); }
  if (feature) {
    if (feature.get('name') != undefined) {
      popup = new ol.Overlay({ element: $("<div />").addClass('info').append(/* 用 jQuery 組表格 */)[0] });
      popup.setPosition(evt.coordinate);
      map.addOverlay(popup);

實際執行後發現兩件事：

  • 只有機場捷運站會跳出資訊表。程式只處理有 name 屬性的圖徵；台北捷運站的欄位是「中文站名、路線名…」，自行車站是「河濱公園、位置…」，都沒有 name，點了沒反應。
  • typeof(popup) != undefined 永遠成立：typeof 回傳字串，例如 "undefined"，和值 undefined 比較永遠不相等。第一次點擊等於呼叫 removeOverlay(undefined)，OpenLayers 會忽略，所以沒出錯。正確寫法是 popup !== undefined。

map.js：styles 的 'metro' 寫了兩次

styles 物件裡 'metro' 先定義成黑色圓點，緊接著又定義成 Google 的紅色圖釘（ol.style.Icon）。物件的鍵重複時，後面的會蓋掉前面的，所以機場捷運站顯示的是紅色圖釘，黑色圓點那段用不到。自行車站沒有定義樣式，顯示 OpenLayers 預設的藍色圓點。

draw.js：Alt＋點選、Delete 刪除

var selectAltClick = new ol.interaction.Select({
  condition: function(e) { return ol.events.condition.click(e) && ol.events.condition.altKeyOnly(e); }
});
map.addInteraction(selectAltClick);
document.addEventListener('keydown', function(evt) {
  if (evt.which == 46) {   // Delete 鍵
    selectAltClick.getFeatures().forEach(function(feature) {
      selectAltClick.getLayer(feature).getSource().removeFeature(feature);
    });
    selectAltClick.getFeatures().clear();
  }
});

condition 決定什麼操作算「選取」：這裡是單擊，而且只按著 Alt。這個選取工具不限圖層，所以實測可以把機場捷運站也刪掉（22 站變 21 站）。不過刪除只發生在瀏覽器記憶體裡，重新整理後資料又會回來。Mac 筆電的 delete 鍵其實是 Backspace，要按 fn＋delete 才是 Delete。

繪圖的部分和上一版的 draw.js 相同：每按一次繪圖按鈕只能畫一個圖徵，畫完 Draw 互動就被移除；下載時 writeFeatures 把座標從 EPSG:3857 轉回 EPSG:4326。

為了在網站上執行所做的修改

  • src/index.html：Bootstrap 3 的 CSS 與 JS 從 http://maxcdn.bootstrapcdn.com 改為 https://，否則 HTTPS 網站會擋下。
  • src/js/map.js：國土測繪中心 WMTS 網址從 http:// 改為 https://。
  • 壓縮檔原本的最外層是 webgis/image/，網站上從 image/ 這層開始放（Dockerfile 和 src/），讓 Dockerfile 裡的 COPY src/ 仍然對得上。
