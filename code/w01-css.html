這包範例在做什麼

對應 CSS 講義的每一個示範檔。建議順序：style.html（inline 樣式）→ idclassStyle.html（id 與 class）→ mp.html（盒模型）→ position.html（定位）→ rwd.html（Bootstrap 格線），最後做 practice.html 這個課堂練習。

範例檔案

重點解說

mp.html：看盒模型最快的方法

執行後在元素上按右鍵 →「檢查」，Styles 面板最下方會畫出 margin（橘）、border、padding（綠）、內容（藍）四層，改數字就能即時看到變化。

position.html：捲動才看得出差別

sticky 與 fixed 在頁面不捲動時看起來一樣。把視窗縮小到需要捲動，觀察 sticky 是「捲到某個位置才黏住」，fixed 則從頭到尾固定在視窗上。

rwd.html：拖拉視窗寬度

用「新分頁開啟」後縮放瀏覽器寬度，或開 DevTools 的裝置模式，看欄位在斷點前後怎麼從並排變成上下排。

動手改改看

  • 把 practice.html 的 inline style 全部搬到一個外部 .css 檔（講義的課堂練習）
  • 在 position.html 加一個 z-index 更大的元素，讓它蓋在原本的 fixed 元素上面
  • 把 rwd.html 的三欄改成「手機一欄、平板兩欄、電腦三欄」
