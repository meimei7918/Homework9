這包範例在做什麼

對應 JavaScript 講義的 12 個示範檔，從放程式碼的位置、變數、型別，到流程控制、函式、事件和 JSON。多數範例把結果印在 Console，所以執行時請按 F12（Mac：Option + Command + I）打開開發者工具。

內嵌的執行框也有自己的 Console。在 DevTools 的 Console 上方下拉選單把 top 切到這個 iframe，或直接按「新分頁開啟」比較好觀察。

原始碼裡以 【說明】 開頭的註解是 AI 逐段加上的中文解說；老師原本的英文註解保留不動，程式本身沒有因為加註解而改變。切到「原始碼」就能邊看邊讀。

重點解說

js_start.html：let 的區塊範圍

let x = 10;
{
  let x = 0;      // 這是另一個 x，只活在大括號裡
  console.log(x); // 0
}
x = 20;           // 改的是外面的 x

同一段範例也示範了 let a, b = null;：a 是 undefined、b 是 null，typeof 分別是 "undefined" 和 "object"。

js_switch_select.html：為什麼永遠顯示 graduate？

這個範例用 addEventListener("change", ...) 監聽選單，再用 switch 依選到的值決定年級。實際執行會發現不管選哪個，都顯示 graduate。原因是：

switch (event.target.value) {  // value 是字串 "1"
  case 1:                       // 比的是數字 1，"1" === 1 為 false
    ...

switch 用的是嚴格比較 ===，表單的值永遠是字串。程式裡的註解「//Number」就是提示：改成 switch (Number(event.target.value))，或把 case 寫成 case "1": 就會正常。

js_json.html：存取巢狀資料

物件用 .key 或 ["key"]，陣列用 [索引]，兩者可以接著寫，例如 data.features[0].properties.name。這就是之後讀 GeoJSON 的方式。

為了在網站上執行所做的修改

  • 12 個 HTML 原本都有 <script src="/script/demo.js">，這支外部檔不在範例包裡，在網站上會出現 404 錯誤，所以改成註解（檔案內有標記「網站版修改」）。其他程式碼沒有更動。

動手改改看

  • 在 js_array.html 用 splice 刪掉陣列中間的兩個元素，並印出刪掉的是什麼（splice 的回傳值）
  • 把 js_function.html 的函式全部改寫成箭頭函式
  • 修改 demo.json 加一筆資料，讓 js_json.html 把所有名字列在網頁上，而不是只印在 Console
