逐段解說

2. 顏色對照表

把「分類 → 顏色」集中在 COLORS 一個物件裡，圖徵上色和圖例都讀同一份，新增分類只要改一個地方，不會出現圖例和地圖顏色對不上的情況。

3. L.geoJSON 的三個選項

選項作用在回傳
pointToLayerPoint一個 Layer（這裡是 circleMarker）
styleLineString、Polygon（和 circleMarker）樣式物件
onEachFeature每一個圖徵不用回傳，拿來綁 popup 或事件

4. fitBounds

layer.getBounds() 取得所有圖徵的外框，map.fitBounds 自動調整縮放，比手動猜 setView 穩定。

5. 自製圖例

任何 HTML 都能變成控制項：建立 L.control()，在 onAdd 回傳一個 DOM 元素即可。

const legend = L.control({ position: "bottomright" });
legend.onAdd = () => { const div = L.DomUtil.create("div"); /* ... */ return div; };
legend.addTo(map);

練習

  • 在 GeoJSON 裡加一條 LineString（例如一段捷運路線），確認 style 有作用
  • 做一個勾選框，只顯示某一個分類（提示：filter 選項）
  • 把 popup 改成滑鼠移過去就顯示的 bindTooltip
