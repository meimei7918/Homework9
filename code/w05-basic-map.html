這包範例在做什麼

老師的 basicMap 範例包，6 個 HTML 一個比一個多一點功能：最小地圖 → 換底圖 → 多底圖切換 → 控制項 → 讀入捷運站 GeoJSON → 點擊捷運站彈出資訊。全部使用 CDN 版的 OpenLayers（ol.js），不需要編譯。

原始碼裡以 【說明】 開頭的註解是 AI 逐段加上的中文解說；老師原本的英文註解保留不動，程式本身沒有因為加註解而改變。切到「原始碼」就能邊看邊讀。

範例檔案

重點解說

map.html：中心點要先轉座標

view: new ol.View({
  center: ol.proj.transform([121.751, 23.8], 'EPSG:4326', 'EPSG:3857'),
  zoom: 4
})

地圖顯示用 EPSG:3857，經緯度（EPSG:4326，經度在前）要先轉換才能當中心點。

map_Basemap.html：WMTS 的圖磚格網

國土測繪中心的 WMTS 要自己算每一層的解析度：以 EPSG:3857 的世界寬度除以 256 得到第 0 層的解析度，之後每層除以 2，並給每層一個 matrixId。算好之後交給 ol.tilegrid.WMTS。這段在 map_control.html、map_geojson.html、map_popup.html 都會重複出現，看懂一次就好。

map_control.html：控制項開關

目前只有 Zoom 是開著的；ZoomSlider、ScaleLine、OverviewMap、MousePosition 都被註解掉了。鷹眼圖（OverviewMap）需要另一組圖層物件，所以檔案裡建了兩組一樣的底圖。用「下載整包」到本機，把註解拿掉再打開，就能看到每個控制項的樣子。

map_popup.html：點擊後彈出資訊

點擊時用 map.forEachFeatureAtPixel(evt.pixel, ...) 找出被點到的捷運站，建立 ol.Overlay，用 jQuery 組出一個表格放上站名、經緯度與車站類型，位置設在 evt.coordinate。每次點擊前先移除上一個 popup，避免疊在一起。

為了在網站上執行所做的修改

  • 國土測繪中心圖磚網址從 http:// 改為 https://（map2、map_Basemap、map_control、map_geojson、map_popup）。網站是 HTTPS，瀏覽器會擋下 HTTP 的圖磚。
  • map_geojson.html 原本讀 http://localhost/webgis/framework/data/metro.geojson（老師電腦上的路徑），改為讀同資料夾的 metro.geojson。
  • map_popup.html 原本透過 sgis.tw 的 proxy.php 讀遠端資料，改為讀同資料夾的 metro.geojson。
  • 以上修改處都有「網站版修改」註解，原始寫法保留在註解中。

動手改改看

  • 把 map.html 的中心改到臺大（121.5397, 25.0174）、zoom 改成 15
  • 在 map_Basemap.html 的下拉選單加一個 Google 衛星影像（lyrs=s）選項
