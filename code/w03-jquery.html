這包範例在做什麼

範例分三組，建議照這個順序看：

  1. script_jq/：講義逐頁的示範，從引入 jQuery、選擇器、事件、特效、取值設值、新增刪除、DOM 走訪到 AJAX
  2. part2/：計時器、jQuery UI 元件（日期、自動完成、滑桿），以及四種圖表函式庫
  3. example/：一個逐版改進的小專案（表格＋按鈕＋對話框），四個版本可以對照看程式怎麼長大

原始碼裡以 【說明】 開頭的註解是 AI 逐段加上的中文解說；老師原本的英文註解保留不動，程式本身沒有因為加註解而改變。切到「原始碼」就能邊看邊讀。

重點解說

jq_jquery.html 與 jq_jquery2.html：對照組

兩份程式幾乎一樣，差別在第二份沒有包在 $(function(){ ... }) 裡，又寫在元素之前，執行時元素還沒產生，所以沒有反應。先跑第二份看它失敗，再對照第一份。

jq_get.html：text() 與 html()

同一個元素，text() 拿到純文字，html() 拿到含標籤的字串。要把使用者輸入的文字放進頁面時用 text() 比較安全，因為它不會把輸入當成 HTML 執行。

example/：小專案怎麼一步步加功能

readme.md 記錄了每一版的變更：v1 建立表格、按鈕與對話框 → v2 新增資料 → v3 格式化時間、清空資料 → v4 插入排序讓新資料在最前、計算合計。點不同版本後切到「原始碼」，比較前後差異，是練習讀程式的好材料。

AJAX 範例

jq_ajax1.html、jq_ajax2.html 會向老師的 PHP 伺服器發請求。打開 Console 看結果；如果伺服器沒有回應或不允許跨網域，會印出「ajax error」。
