這包範例在做什麼

一個有完整介面的 WebGIS 骨架（左側圖層面板一開始是隱藏的，按導覽列的「圖層列表」打開）：上方導覽列、左側可收合的圖層面板（jQuery UI Accordion）、右側地圖。底圖可以在 OSM、Google、臺灣通用電子地圖之間單選，疊加圖層可以勾選捷運站、捷運路線、縣市界。期末專題可以從這個骨架開始改。

內嵌框比較窄，建議按「新分頁開啟」看完整介面。縣市界檔案約 14 MB，第一次勾選要等幾秒。

原始碼裡以 【說明】 開頭的註解是 AI 逐段加上的中文解說；老師原本的英文註解保留不動，程式本身沒有因為加註解而改變。切到「原始碼」就能邊看邊讀。

重點解說

index.html：載入順序很重要

jQuery、jQuery UI、Bootstrap、OpenLayers 在 head 載入；map.js 和 main.js 放在 body 最後、地圖 div 之後，因為 map.js 一執行就要把地圖掛到 #map 上。

map.js：用一個物件管理所有圖層

layers 物件的每一筆都有 title、type（base 或 overlay）、layer。initLayers() 跑迴圈，base 產生單選鈕、overlay 產生勾選框，並把圖層加進地圖；setLayer(key) 讓選中的底圖可見、其他隱藏。樣式寫在 styles 物件（捷運站黑色圓點、捷運線灰色虛線、縣市界藍色），但 initLayers() 裡套用樣式的那一行被註解掉了，所以目前畫面上是 OpenLayers 預設的藍色樣式；把那行打開就會換成 styles 的樣式。

檔案開頭有一段 ol.Geolocation 定位程式，目前整段被註解掉；打開後會在第一次取得位置時把地圖移到使用者所在處並放大到 14 級。

main.js：讓地圖跟著版面變大小

側邊欄開關或視窗大小改變時，updateSize() 重算容器高度、刷新 Accordion，並呼叫 map.updateSize()。沒有這一步，地圖會以為自己還是原本的大小，出現空白或變形。

draw.js：寫好了但沒有接上

draw.js 實作了繪製（Draw）、編輯（Select＋Modify）、匯出 GeoJSON 下載，但 index.html 沒有載入它，介面上也沒有對應的按鈕（.btn-draw、#btn-edit、#btn-json）。這正好是一個好練習，見本週課後練習的實作題 3。

為了在網站上執行所做的修改

  • index.html 的 Bootstrap 3 CSS 與 JS 從 http://maxcdn.bootstrapcdn.com 改為 https://，否則 HTTPS 網站會擋下。
  • map.js 的國土測繪中心 WMTS 網址從 http:// 改為 https://。
